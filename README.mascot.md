# KGY 看板娘素材

当前使用 `source/img/mascot/kgy-snow-girl-v3.png`，为透明背景角色图（1024 × 1536，约 1.7 MB），参考本站 `source/img/avatar.jpg`，使用内置 imagegen 工具生成并按用户选定的版本局部编辑。冷银灰长发带少量淡金高光，浅红眼睛，神情参考冰辉夜的清冷感；简洁黑裙、双手轻放身前的站姿、较大的黑色翅膀。按最终要求让裙摆稍短、身形和腿部比例更修长，头发更柔顺，翅膀向内弯成轻微包裹两侧的轮廓。头发保留用户指定版本的长度。旧版 `kagiel-winged-girl.png` 留作备份，原头像不变。

角色名称：KGY。简介：ONLY KGY。

最终外观：略过膝盖的白袜、小腿肚高度的黑色哥特系带靴；单只较宽的黑色腿圈戴在画面右侧腿部的皮肤上，与袜口留有间隔；银色雪花项链；角色右手腕（画面左侧）的细银色手环和黑色皮筋。饰品保持小巧，保留冷银灰长发、浅红眼睛、清冷表情及乖巧站姿。最终局部编辑提示词完整记录在 `tools/mascot/kgy-design-v3-prompt.md`。

动画由 `source/js/mascot.js` 与 `source/css/mascot.css` 在浏览器中实现，不是 Cubism / Live2D 模型。新版 canvas 使用 512 × 768 绘制缓冲区，与原图 2:3 比例一致，避免人物被横向拉宽。眼睛区域按当前素材重新标定：UV 中心 `(0.468, 0.872)`、`(0.541, 0.882)`，椭圆半径 `(0.021, 0.011)`。对话头像和紧凑模式同步调整为竖图裁切。替换图片时需重新标定这些位置。

默认使用本地简短对话：学习小题、音乐、心情、读书、电影、游戏、饮食和日常话题，由 `source/js/mascot-dialogue.js` 提供会话状态及后续选项。聊天文案使用自然语气，不再提及「羽翼」等角色设定。角色图片约 1.7 MB，浏览器加载一次并在站内 PJAX 导航中保留。

可手动开启免费 AI 聊天，使用 [WebLLM](https://webllm.mlc.ai/) 在浏览器 Worker 中运行 `Qwen2.5-0.5B-Instruct-q4f32_1-MLC`。无 API 密钥、服务端聊天接口或按次数收费；首次需要下载约 300 MB 模型和运行文件，权重本身约 278 MB。下载来源为官方 MLC 的 Hugging Face 模型仓库与模型运行库，浏览器 Cache API 会保存下载文件。缓存被清理、首次访问另一个域名时需要重新下载。关闭 AI 会终止 Worker，释放模型运行资源，保留下载缓存。

需要 HTTPS（本地 localhost 也可）、支持 WebGPU 的浏览器及足够内存，优先新版 Chrome / Edge。加载失败或设备不支持时继续简短对话，可以重试；加载和回复均可取消。小模型回复能力有限，不提供实时查询。模块入口为 `source/js/mascot-ai.mjs` 和 `source/js/mascot-ai-worker.mjs`，仅点击开启后才加载运行库与模型，普通访问不会下载模型。

WebLLM 0.2.85 的 ESM 发布文件取自官方 npm 包 `@mlc-ai/web-llm@0.2.85`，原样保存于 `source/vendor/webllm-0.2.85/index.js`（SHA-256：`341BAE95822BFEE1D0FD6A0E6CD2DB8613BB8EDF809390AC142FBA36EC17792C`），同目录保留 Apache 2.0 LICENSE。Qwen 模型亦为 Apache 2.0，参见 [原模型说明](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct)。未使用收费云服务。

输入仅用于当前浏览器中的简短对话或本地推理，不传给外部聊天服务，不写入 localStorage。当前会话保留最近 24 条消息，AI 使用最近最多 8 条且累计最多 900 字的上下文；「重新聊」清除对话和本地昵称。整个看板娘标记 `translate="no"`，输入和消息不参与本站机器翻译。

使用：点击少女或左下角星形按钮打开对话；可以输入短句或选择快捷话题。展开「免费 AI 聊天」并点击「开启 AI 聊天」，等待准备完成后即可自由提问。Escape 收起对话。显示偏好存入浏览器本地；打开音乐时临时避让，收起音乐后恢复。
