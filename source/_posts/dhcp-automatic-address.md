最近做网络设置题时，题目给出了一组很完整的信息：网络地址 192.168.1.0、子网掩码 255.255.255.0、网关 192.168.1.1、DNS 服务器 192.168.1.5。最关键的条件却是最后一句：PC 要使用 DHCP 服务器。

所以答案是**设置为自动获取 IP 地址**。看见一个似乎没被占用的地址，就手动填进去，并不符合题意。

<!-- more -->

## DHCP 分配的是什么

DHCP 是 Dynamic Host Configuration Protocol，动态主机配置协议。客户端可以向服务器请求网络配置，服务器按规则提供地址及相关参数。

| 参数 | 作用 | 题目中的例子 |
| --- | --- | --- |
| IP 地址 | 标识主机的网络接口 | 由 DHCP 服务器分配 |
| 子网掩码 | 划分网络部分与主机部分 | 255.255.255.0 |
| 默认网关 | 转发发往其他网络的数据 | 192.168.1.1 |
| DNS 服务器 | 提供域名解析服务 | 192.168.1.5 |

这些角色可以由同一台设备承担，也可以分开。题目里 DNS 和网关的地址不同，正好提醒我不要把它们混成一个概念。

## 初次获取地址的四步

常见的初始流程可以用 DORA 记忆：

1. Discover：客户端寻找 DHCP 服务器。
2. Offer：服务器提出可以提供的配置。
3. Request：客户端请求采用其中一份配置。
4. Acknowledge：服务器确认分配。

地址通常带有租期，客户端需要续租。这里记的是典型初次分配流程，续租不一定重新走完整的四步。

## 为什么其他选项不对

在这个 /24 网络里，192.168.1.0 是网络地址，192.168.1.255 是广播地址，通常都不能分给普通主机。192.168.1.1 已经是网关，重复使用会产生地址冲突。

192.168.1.150 在数值上属于可用主机范围，但“属于范围”和“符合配置要求”是两回事。题目要求 DHCP，就应该让服务器分配，而不是自行猜一个没有使用的地址。

日语题里，自动获取是「IPアドレスを自動的（じどうてき）に取得（しゅとく）する」。以后先圈出 DHCP 这个条件，再看各个地址的角色，解题会清楚很多。
