写出 Hello World 之后，程序接下来需要处理的通常是会变化的数据：现在有多少本书、一次购买花了多少钱、几次考试的平均分是多少。变量让程序可以给数据取名字，读取当前值，按照计算结果更新它，并把结果交给后面的语句继续使用。

学习变量时，不必先背完所有类型和符号。先读懂一段只有几行的程序，跟踪每条语句执行后数值怎样变化，再逐步加入小数、字符、输入和作用域，会更容易理解。本文使用 C17 的基础写法；编辑、编译与运行环境可以先参考[Hello World 入门笔记](/posts/c-hello-world-editors/)，数值表示与浮点误差可以结合[数值表示笔记](/posts/number-representation-logic/)阅读。

## 先运行一个只有一个变量的完整程序

新建 `variables.c`，保存下面的代码。先不要改动，观察每次输出为什么不同：

```c
#include <stdio.h>

int main(void)
{
    int apples = 3;
    printf("Before: %d\n", apples);

    apples = apples + 2;
    printf("After: %d\n", apples);

    return 0;
}
```

程序输出为：

```text
Before: 3
After: 5
```

`apples` 是变量名，表示苹果数量。第一条变量语句建立了一个保存整数的对象，并把初始值设为 3；第一次 `printf` 读取它此时的值，所以输出 3。随后程序读取原来的 3，计算 `3 + 2`，再把结果 5 写回同一个变量；第二次输出读取的是更新后的值，因此得到 5。

这里的更新按语句发生，屏幕上已经打印的 `Before: 3` 不会被追溯修改。后续语句只能读取变量当时保存的值，除非程序另外保存旧值，否则不能通过同一个变量名直接找回更新前的 3。

使用 GCC 时，可以在 PowerShell 中编译和运行：

```powershell
gcc -std=c17 -Wall -Wextra -Wpedantic variables.c -o variables.exe
.\variables.exe
```

`-std=c17` 指定语言版本，后面三个选项启用常见警告。每次修改源代码后都要重新编译；如果编译失败，旧的可执行文件可能还在，不要把运行旧程序的结果误认为新代码已经生效。

## 把类型名称和初始值分开理解

变量在日语中是「<span lang="ja" translate="no">変数・へんすう</span>」，英语是 variable。对下面的基础写法，可以依次读出四个部分：

```c
int apples = 3;
```

| 部分 | 表示什么 | 在这个例子中的含义 |
| --- | --- | --- |
| `int` | 类型，type | 按整数类型保存和处理这个对象的值 |
| `apples` | 名称，identifier | 后面通过这个名字引用该对象 |
| `= 3` | 初始化内容，initializer | 建立对象时给它初始值 3 |
| `;` | 语句或声明的结束标记 | 这一条声明到此结束 |

可以先把普通变量理解为一个有类型、能通过名字访问的存储对象。名字用于写程序，类型决定允许的值和相关运算规则，当前值则记录此刻的数据状态；编译器可能优化具体的存储方式，因此不必把每个变量想成永远占据某个固定内存格子。

`int apples = 3;` 与 `int books = 3;` 建立的是两个不同对象，即使初始值相同，修改其中一个也不会自动修改另一个。反过来，变量的值可以改变，但同一个已声明对象的类型不会因为赋值而变成另一种类型。

## 声明定义初始化和赋值各做了什么

这几个术语经常一起出现，但关注的动作不同。

| 术语 | 日语与英语 | 关注的动作 |
| --- | --- | --- |
| 声明 | <span lang="ja" translate="no">宣言</span> / declaration | 告诉编译器名称及其类型等信息 |
| 定义 | <span lang="ja" translate="no">定義</span> / definition | 对这里的普通对象而言，建立它所需的存储 |
| 初始化 | <span lang="ja" translate="no">初期化</span> / initialization | 在对象建立时设置初始值 |
| 赋值 | <span lang="ja" translate="no">代入</span> / assignment | 向已经存在、允许修改的对象写入值 |

在 `main` 的函数体中，`int apples = 3;` 同时完成了声明、定义和初始化。之后的 `apples = 5;` 没有再写类型，它操作的是已经存在的变量，所以是赋值。

也可以先定义，后赋值，但第一次读取前必须已经写入有效值：

```c
int apples;
apples = 3;
printf("%d\n", apples);
```

这段代码可以放进 `main` 中使用。第一行没有初始化，第二行在读取前完成赋值，所以第三行能够得到 3。

若把第二行删掉，直接读取这里未初始化的普通局部 `int`，就不能期待得到 0，也不能把某次运行出现的数字当成可靠默认值。这种值是不确定的，在这里读取会导致未定义行为，程序的结果没有可依赖的保证。入门时最稳妥的习惯，是定义后立即给出有意义的初始值。

声明不一定总是定义，例如多个源文件之间还会用到 `extern` 声明。这个区别先知道即可；当前的练习先把变量放在 `main` 内，并采用“一行一个变量、直接初始化”的写法。

## 赋值号按右边求值再写入左边

数学等式 `x = x + 1` 不可能对有限整数 x 成立，但 C 中的 `=` 表示赋值，不是在声明一个永久成立的等式。程序会先求右侧表达式的值，再把结果转换为目标类型并写入左边。

例如：

```c
int count = 4;
count = count + 1;
```

执行第二行时，右边的 `count` 先读取旧值 4，所以算式变成 `4 + 1`。计算得到 5 后，左边的 `count` 被更新为 5，整个过程就结束了；它不会因为值变了而再次自动计算同一行。

比较是否相等要使用 `==`。例如 `count == 5` 是一个比较表达式，结果用整数 1 表示成立、0 表示不成立；它本身不会把 count 改成 5。相应地，`!=` 表示不相等。

| 表达式 | 作用 |
| --- | --- |
| `count = 5` | 把 5 写入 count |
| `count == 5` | 比较 count 的当前值是否等于 5 |
| `count != 5` | 比较 count 的当前值是否不等于 5 |

赋值左侧需要是允许修改的目标。`count = 5;` 合法，`5 = count;` 则不合法，因为数字字面量 5 不是可以被改写的变量。若写成 `if (count = 5)`，这通常仍是有效的 C 语法，却会执行赋值，难以表达原本想要的比较，因此应认真阅读编译器警告。

## 用执行过程表跟踪多个变量

当代码里有多个变量时，不要靠“看起来像数学公式”猜结果，而应按语句顺序记录状态：

```c
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = a;

    a = 8;
    b = b + 2;

    printf("a = %d, b = %d\n", a, b);
    return 0;
}
```

| 执行完的语句 | a 的当前值 | b 的当前值 | 原因 |
| --- | --- | --- | --- |
| `int a = 3;` | 3 | 尚未定义 | 建立 a 并初始化 |
| `int b = a;` | 3 | 3 | 读取此时的 a，把值复制给新变量 b |
| `a = 8;` | 8 | 3 | 只更新 a |
| `b = b + 2;` | 8 | 5 | 读取 b 的旧值 3，计算后写回 b |

最终输出是 `a = 8, b = 5`。`int b = a;` 复制的是执行到这一行时 a 的值，并没有建立“b 永远跟着 a 变化”的关系。

![将 a 的值复制给 b 后，修改 a 不会自动修改 b](/img/notes/c-variable-copy.svg)

这个规则也能解释计算结果为什么不会自动更新：

```c
int price = 10;
int quantity = 2;
int total = price * quantity;

quantity = 3;
```

最后一行执行完，quantity 变成 3，但 total 仍然是此前算出的 20。若希望总价随这次修改重新计算，必须再执行 `total = price * quantity;`，它才会更新为 30。

## 变量名要合法也要能说明含义

初学阶段可以使用英文字母、数字和下划线组合命名，但不要用数字开头，不要包含空格，也不要使用 `int`、`double`、`return` 等关键字。为了避开库和实现保留的名称，也不要自行使用下划线开头的名字。

| 名称 | 是否适合入门练习 | 说明 |
| --- | --- | --- |
| `age` | 适合 | 可以表示年龄 |
| `student_count` | 适合 | 可以表示学生人数 |
| `score1` | 适合 | 数字不在开头 |
| `1score` | 不合法 | 以数字开头 |
| `student count` | 不合法 | 中间有空格 |
| `int` | 不合法 | 是语言关键字 |
| `Age` 与 `age` | 是两个不同名称 | C 区分大小写 |

名称最好同时交代单位，例如 `time_seconds` 表示秒数，`price_cents` 表示以分为单位的金额。`a`、`b` 适合演示赋值，但在实际程序中，`total_score` 比 `x` 更容易说明保存的内容。

同一作用域内，不能把同名变量再定义一次来“更新类型”。若已经写了 `int age = 18;`，后面只想修改年龄，应写 `age = 19;`，而不是再写 `int age = 19;`。

## 先掌握整数小数字符和真假四类值

C 的类型不只决定能否写小数，还会参与运算和输入输出。入门先掌握下面几种：

| 常见类型 | 适合表示什么 | 示例 |
| --- | --- | --- |
| `int` | 范围内的整数 | `int count = 5;` |
| `double` | 浮点数，常用于带小数的计算 | `double height = 1.75;` |
| `float` | 另一种浮点类型，精度通常低于 double | `float rate = 0.5f;` |
| `char` | 一个字符编码单元，也是一种整数类型 | `char grade = 'A';` |
| `bool` | 真或假；C17 中使用前包含 `<stdbool.h>` | `bool passed = true;` |

`3` 是整数常量，`3.0` 是 double 类型的浮点常量，`3.0f` 则是 float 类型的浮点常量。它们在数学上可以表示同样的量，但在 C 的表达式中，类型会影响后续计算采用的规则。

`int` 能表示的范围有限，也不是在所有平台上都固定占四字节。可以从 `<limits.h>` 中读取 `INT_MIN` 和 `INT_MAX`，通过 `sizeof` 查询对象或类型占用的字节数：

```c
#include <stdio.h>
#include <limits.h>

int main(void)
{
    int count = 5;

    printf("sizeof(int) = %zu\n", sizeof(int));
    printf("sizeof(count) = %zu\n", sizeof(count));
    printf("int range: %d to %d\n", INT_MIN, INT_MAX);
    return 0;
}
```

`sizeof` 的结果类型是 `size_t`，所以使用 `%zu` 输出。具体数字取决于实现，不能把某次输出当成所有计算机的统一规定；C 中一字节包含多少位，可查看 `<limits.h>` 中的 `CHAR_BIT`。

范围限制也适用于计算的中间结果。有符号 int 的算术结果若超出可表示范围，会导致未定义行为，不能假设它总会自动从最大值绕回最小值；后面把结果存进更大的类型，也不能修复已经在较小类型中发生的溢出。入门例子先使用明确处于范围内的小数值，再逐步学习范围检查。

## printf 需要按类型读取要输出的值

`printf` 中双引号里的内容是格式字符串。普通文字按原样输出，`%d`、`%f` 等转换说明则告诉函数，应该怎样解释并显示后面的参数。

```c
#include <stdio.h>

int main(void)
{
    int age = 18;
    double height = 1.75;
    char grade = 'A';

    printf("age = %d\n", age);
    printf("height = %.2f\n", height);
    printf("grade = %c\n", grade);
    return 0;
}
```

输出为：

```text
age = 18
height = 1.75
grade = A
```

`%.2f` 中的 `.2` 表示按这种格式显示两位小数，影响的是本次输出形式，不会把变量永久改写为只保存两位小数。`\n` 是换行，末尾的 age、height、grade 才是实际传入的值，双引号里的变量名只是文字。

| 需要输出的数据 | 常用格式 |
| --- | --- |
| `int` | `%d` |
| `unsigned int` | `%u` |
| `long long` | `%lld` |
| `double` | `%f`，或 `%.2f` 等指定显示精度 |
| `char` 表示的普通单字节字符 | `%c` |
| `size_t`，例如 sizeof 的结果 | `%zu` |

把 `printf("%d\n", height);` 当作“小数转整数”是错误的：格式说明与参数类型不匹配，可能产生未定义行为，而不是按想象自动转换。需要转换时，应先写出合适的表达式，再用与结果匹配的格式。

float 传给 `printf` 时会提升为 double，所以也用 `%f` 输出。后面用 `scanf` 输入时规则不同，不能只记住“带小数就一律写 f”。

## 整数除法在存入 double 之前已经完成

下面这个问题尤其容易影响平均分和比例计算：

```c
#include <stdio.h>

int main(void)
{
    int total = 5;
    int count = 2;

    double a = total / count;
    double b = (double)total / count;
    double c = total / 2.0;

    printf("a = %.1f\n", a);
    printf("b = %.1f\n", b);
    printf("c = %.1f\n", c);
    return 0;
}
```

结果为：

```text
a = 2.0
b = 2.5
c = 2.5
```

计算 a 时，右边的两个操作数都是 int，因此先执行整数除法。C17 的整数除法会舍去商的小数部分，向零截断，所以 `5 / 2` 得到整数 2；之后再把 2 转换成 double，得到的是 2.0，小数部分已经无法恢复。

计算 b 时，`(double)total` 先把参与除法的 total 值转换为 double，然后另一操作数也按相应规则转换，执行浮点除法，所以得到 2.5。这个强制类型转换（<span lang="ja" translate="no">型キャスト</span> / cast）作用于表达式的值，不会把原变量 total 永久变成 double。

计算 c 时，`2.0` 本来就是 double 常量，因此同样进行浮点除法。相反，`(double)(total / count)` 是先完成整数除法，再转换结果，仍然只能得到 2.0。

| 写法 | 先发生什么 | 结果 |
| --- | --- | --- |
| `5 / 2` | 两个整数相除 | 整数 2 |
| `5 / 2.0` | 浮点除法 | double 值 2.5 |
| `(double)5 / 2` | 先转换左侧值，再除法 | double 值 2.5 |
| `(double)(5 / 2)` | 先整数除法，再转换结果 | double 值 2.0 |

反过来，把范围内的有限小数赋给 int，会舍去小数部分，例如 `int x = 3.9;` 得到 3，`int y = -3.9;` 得到 −3，这不是四舍五入。若数值超出目标整数类型的可表示范围，则不能依赖这种转换，所以不能把“写一个 int”当作任意数据都安全的处理方式。

## 运算顺序和变量更新都需要逐步检查

加减乘除分别使用 `+`、`-`、`*`、`/`，取余使用 `%`。乘、除、取余的优先级高于加减，所以 `2 + 3 * 4` 得到 14，而 `(2 + 3) * 4` 得到 20。

对正整数，`17 / 5 = 3`、`17 % 5 = 2` 可以理解为商三余二。整数除法和取余的除数不能为零，其他中间结果也要处于相应类型能够表示的范围内。

简单整数变量的更新可以使用复合赋值：

```c
int count = 4;
count += 3;
count -= 2;
count *= 5;
```

这里每一步的值分别是 4、7、5、25。对这种简单变量，`count += 3` 可以按“先算 count+3，再写回 count”理解。

`count++` 和 `++count` 都会让 count 增加 1，但它们作为更大表达式的一部分时，提供的值不同。可以用下面两段互相独立的代码对照：

```c
int count = 4;
int old_value = count++;
```

此时 old_value 为 4，count 为 5，因为后缀 `++` 提供增加前的值。另一种写法是：

```c
int count = 4;
int new_value = ++count;
```

此时 new_value 和 count 都为 5，因为前缀 `++` 提供增加后的值。初学时，可以先把自增单独写成一句，避免把多次更新挤进同一个表达式。

例如 `i = i++;` 或 `i++ + i++` 不能作为“猜执行顺序”的练习；在 C17 中，这类未按规则排序的更新会导致未定义行为，没有应当背诵的固定结果。运算符优先级也不等于所有子表达式都按从左到右的时间顺序执行。

## 字符小数和真假值各有边界

字符常量使用单引号，例如 `char grade = 'A';`；字符串使用双引号，例如 `"A"`。`'A'` 表示一个字符值，`"A"` 则是包含字符 A 和结尾空字符的字符串，不能当成同一个东西使用。

同样，`'8'` 是字符 8 的编码值，不是整数 8。若已经确认一个字符是 `'0'` 到 `'9'` 之一，可以用 `digit - '0'` 得到对应整数，因为 C 保证十进制数字字符的编码连续；不要把 `'A'` 必然等于 65 当成跨平台规则。

```c
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    char digit = '8';
    int number = digit - '0';
    bool passed = number >= 6;

    printf("digit = %c\n", digit);
    printf("number = %d\n", number);
    printf("passed = %d\n", passed);
    return 0;
}
```

输出依次是 `digit = 8`、`number = 8`、`passed = 1`。第一行显示字符，第二行显示整数，外观相似，但变量类型和计算含义不同。`>=` 表示大于或等于，比较结果成立，赋给 bool 后表示真。

在这里采用的 C17 中，`<stdbool.h>` 提供 bool、true、false，底层布尔类型是 `_Bool`。向 bool 转换时，零变成假，非零变成真；它适合记录“是否通过”“是否找到”等状态。一个普通 char 也不能一般性地保存任意完整汉字，字符编码和多字节文本需要另外学习。

对于 double 和 float，还要注意有限精度。大多数常见实现采用二进制浮点格式，一些十进制小数不能精确保存，因此不要把“输出看起来有两位小数”理解成内部一定精确到百分之一。基础金额练习可以采用整数记录最小单位，但整数同样需要检查范围和单位。

## const 表示这个对象不应被普通赋值修改

如果一个量建立后不打算在程序中更改，可以加上 const 限定：

```c
const int minutes_per_hour = 60;
int hours = 2;
int minutes = hours * minutes_per_hour;
```

此时 minutes 为 120。后面可以改变 hours，也可以重新计算 minutes，但不能再用普通赋值给 minutes_per_hour 写入新值；这样的代码应当在编译阶段被诊断出来。

`const` 不表示程序“只会计算一次”，而是限制通过相应对象进行修改。也不要把 C 的 const 对象简单等同于所有语法位置都能使用的编译期常量；当前阶段，把它用于表达固定参数即可。

区别于变量名，直接写在代码里的 `60`、`2.5`、`'A'` 是字面常量。用有含义的 const 名称代替反复出现的数字，可以让计算中的单位和用途更清楚，但没有必要把所有只用一次的数字都包装成新变量。

## scanf 把输入写入变量需要提供位置

`printf` 读取值并输出，而 `scanf` 需要根据输入把值写到指定对象中。对本文的普通数值变量，`&age` 表示取得 age 的地址，让函数知道应该写入哪里。

下面这个练习使用 int 可表示的整数作为输入，并进一步限定年龄在 0～120，例如输入 18：

```c
#include <stdio.h>

int main(void)
{
    int age = 0;

    printf("Enter an integer age: ");
    fflush(stdout);

    if (scanf("%d", &age) != 1) {
        printf("Input error.\n");
        return 1;
    }

    if (age < 0 || age > 120) {
        printf("Age must be between 0 and 120.\n");
        return 1;
    }

    printf("Next year: %d\n", age + 1);
    return 0;
}
```

这里先把 age 初始化为 0，然后等待输入。`fflush(stdout)` 用于及时显示没有换行的提示文字；它操作的是输出，不要照着写成 `fflush(stdin)` 来清理输入，因为那不是可移植的标准 C 用法。

`scanf` 的返回值说明成功匹配并赋值了多少项。这里要求读入一个整数，所以只有返回 1 才继续；输入 `abc` 等不符合整数转换的文本时，程序输出错误信息，并通过 `return 1` 提前结束。`if` 括号里的 `!= 1` 是比较，不是赋值。

第二个 if 使用 `||` 表示“或”，年龄小于 0 或大于 120 时就提前结束，从而保证继续计算的 `age+1` 也在 int 范围内。但检查返回值和后续年龄范围，仍不能使 `%d` 安全处理任意超长数字；在 C17 中，若输入转换结果超出接收对象范围，行为未定义。需要接收任意用户文本的程序，应使用 `fgets` 读取一行，再用 `strtol` 等函数检查范围和剩余文本，不能仅靠这个简化输入模板。

输入与输出的格式要分别记：

| 变量类型 | printf 输出 | scanf 输入 |
| --- | --- | --- |
| `int age` | `printf("%d", age)` | `scanf("%d", &age)` |
| `float rate` | `printf("%f", rate)` | `scanf("%f", &rate)` |
| `double height` | `printf("%f", height)` | `scanf("%lf", &height)` |
| `char grade` | `printf("%c", grade)` | `scanf(" %c", &grade)` |

`scanf` 中 `%f` 接收 float 的地址，`%lf` 接收 double 的地址，二者不能互换。字符输入前的空格用于跳过前面的空白字符，例如上一次回车留下的换行；它也意味着这个写法不适合专门读取空格或换行本身。

## 用一个小程序串联数量金额和找零

下面用整数“分”表示金额：笔记本单价 650 分，购买三本，预算 3000 分。把数量、单价、总价和余额分别命名，会比直接写一长串数字更容易检查。

```c
#include <stdio.h>

int main(void)
{
    const int price_cents = 650;
    int quantity = 3;
    int budget_cents = 3000;

    int total_cents = price_cents * quantity;
    int remaining_cents = budget_cents - total_cents;

    printf("Quantity: %d\n", quantity);
    printf("Total: %d.%02d\n",
           total_cents / 100, total_cents % 100);
    printf("Remaining: %d.%02d\n",
           remaining_cents / 100, remaining_cents % 100);

    return 0;
}
```

结果为：

```text
Quantity: 3
Total: 19.50
Remaining: 10.50
```

总价为 `650 × 3 = 1950` 分，预算减去总价得到 1050 分。对这些非负金额，除以 100 得到整数部分，余数表示不足一整单位的分；`%02d` 表示至少两位宽度，不足时用 0 补齐，因此余数 5 会显示成 05。

练习时可以只修改 quantity。若改成 4，总价应为 2600 分、余额为 400 分，对应显示 26.00 和 4.00。若改成 5，总价 3250 分就会超过预算，这已经需要进一步设计“不足付款时怎样处理”，而不能假设当前的非负金额格式对任何负数都适用。

修改程序时，还要检查乘法的中间结果是否超出 int 范围。给金额换成整数单位，只解决了这类基础加减乘法中小数表示的问题，并没有让金额范围自动变得无限大。

## 用同一个变量规则推导平均分与温度换算

理解上面的“输入或已有数据 → 计算 → 保存结果 → 输出”之后，可以把它迁移到不同任务。

先计算三次成绩 80、81、83 的平均分。总分 244，人数为 3，若使用整数除法只能得到 81，因此要在除法之前转换：

```c
int score1 = 80;
int score2 = 81;
int score3 = 83;

int total_score = score1 + score2 + score3;
double average = (double)total_score / 3;

printf("Average: %.2f\n", average);
```

这段代码放入包含 `<stdio.h>` 的 main 中，会显示 `Average: 81.33`。如果把 score3 改成 86，并重新编译运行，总分变为 247，显示结果就变成 82.33；如果是在运行中修改 score3，则还需要重新执行总分和平均分的计算语句。

再看摄氏温度转华氏温度，数学公式是 `F = C × 9/5 + 32`。可以写成：

```c
double celsius = 25.0;
double fahrenheit = celsius * (9.0 / 5.0) + 32.0;

printf("Fahrenheit: %.1f\n", fahrenheit);
```

结果为 77.0。这里明确使用浮点常量，保证比例是 1.8；若写成 `celsius * (9 / 5) + 32`，括号中会先做整数除法得到 1，整个式子变成 57.0。改变变量保存的数据，并不意味着可以忽略表达式本身的类型规则。

最后可以把总秒数分成分钟和剩余秒数：

```c
int total_seconds = 135;
int minutes = total_seconds / 60;
int seconds = total_seconds % 60;

printf("%d min %d sec\n", minutes, seconds);
```

输出为 `2 min 15 sec`。这与金额拆分使用了同一组规则：整数除法得到完整单位数，取余得到剩余部分，只是单位从“分与整单位”换成了“秒与分钟”。

## 交换两个变量时保留即将被覆盖的旧值

设 a 为 3、b 为 8，如果依次写 `a = b; b = a;`，并不能交换它们。第一句已经把 a 改成 8，第二句读到的 a 也是 8，原来的 3 已经丢失。

需要先用一个临时变量保存 a 的旧值：

```c
#include <stdio.h>

int main(void)
{
    int a = 3;
    int b = 8;

    int temporary = a;
    a = b;
    b = temporary;

    printf("a = %d, b = %d\n", a, b);
    return 0;
}
```

| 执行步骤 | a | b | temporary |
| --- | --- | --- | --- |
| 保存旧 a | 3 | 8 | 3 |
| 将旧 b 写入 a | 8 | 8 | 3 |
| 将保存的旧 a 写入 b | 8 | 3 | 3 |

最终输出 `a = 8, b = 3`。临时变量的作用不是一种神秘的交换语法，而是在旧值被覆盖前多保留一份。交换商品价格、两个成绩或排序中的相邻元素，都可以从这个过程继续推导。

## 作用域说明名字在什么位置可见

作用域（<span lang="ja" translate="no">スコープ</span> / scope）描述在代码中的哪些位置可以通过某个名称引用对象。本文大部分变量都定义在 main 的花括号里，属于局部变量，通常从声明处开始，到相应代码块结束前可见。

```c
#include <stdio.h>

int main(void)
{
    int outer = 10;

    {
        int inner = 3;
        printf("Inside: %d\n", outer + inner);
    }

    printf("Outside: %d\n", outer);
    return 0;
}
```

输出是 `Inside: 13` 和 `Outside: 10`。内部代码块可以看到外部已经可见的 outer，但 inner 的名称在内部代码块结束后就不可见，因此不能把最后的输出改成直接读取 inner。

若内部又定义了一个名为 outer 的新变量，就会发生遮蔽：在相应内部范围中，这个名字引用的是新对象。它不等于把外部变量重新初始化；初学时可以优先使用不冲突的名称，减少跟踪状态的难度。

## 作用域和存储期不是同一个概念

普通自动局部变量的存储期通常随所在代码块的一次执行而开始和结束。定义在函数外的文件作用域对象，以及用 static 定义的局部对象，具有静态存储期，存在于程序整个运行期间；它们未显式初始化时会按规则初始化，整数对象得到 0。

这一规则不能反过来套到前面未初始化的普通自动局部 int 上。还要区分“对象存在多久”和“名字在哪里可见”：一个 static 局部对象可以持续存在，但它的名称仍然受局部作用域约束。

函数参数也有自己的对象。普通整数按值传递时，函数里改变参数，并不会自动改变调用者的变量：

```c
#include <stdio.h>

void change_copy(int value)
{
    value = 99;
    printf("Inside function: %d\n", value);
}

int main(void)
{
    int score = 80;

    change_copy(score);
    printf("In main: %d\n", score);
    return 0;
}
```

输出依次是 99 和 80。调用函数时，score 的当前值被复制给参数 value，因此改变的是参数对象。若希望函数把计算结果传回来，可以先学习返回值，并把返回结果赋给 score；通过地址间接修改对象，则属于后续指针部分。

## 用常见错误反查自己漏掉了哪一步

| 现象或写法 | 问题所在 | 应当检查什么 |
| --- | --- | --- |
| 未初始化的普通局部变量直接输出 | 读取前没有获得有效值 | 定义时初始化，或保证使用前赋值成功 |
| `double average = 5 / 2;` 得到 2.0 | 右侧先做了整数除法 | 在除法前让操作数采用合适的浮点类型 |
| 修改 quantity 后 total 不变 | 保存的是此前计算结果 | 修改基础数据后重新执行计算 |
| `printf("%d", a_double);` | 输出格式与参数不匹配 | 核对表达式类型和格式说明 |
| `scanf("%d", age);` | 对普通 int 没有提供接收地址 | 使用 `&age` 并检查返回值 |
| double 输入使用 `%f` | 传入地址的类型不匹配 | double 使用 `%lf` |
| 同一范围内再次定义同名变量 | 把更新误写成新定义 | 更新时不重复写类型 |
| `int a, b = 0;` 后以为二者都为零 | 只给 b 提供了初始化 | 分行写清 `int a = 0; int b = 0;` |
| 两句赋值后交换失败 | 覆盖了仍然需要的旧值 | 先用临时变量保存 |
| 以为屏幕显示等于内部精确值 | 忽略了输出格式和有限精度 | 分清内部保存与格式化显示 |

某些错误能在编译时被发现，某些只是警告，还有些可能正常生成程序却计算错误。因此，“编译成功”和“结果符合要求”需要分别检查，最好先在纸上写出小例子的预期结果，再运行程序对照。

## 先预测结果再做分层练习

### 第一层检查是否能跟踪赋值

将下面的片段放入 main，先预测最后两个变量的值：

```c
int a = 2;
int b = a + 3;
a = 10;
b += a;
```

答案是 a 为 10、b 为 15。b 初始化时得到 `2+3 = 5`，a 变成 10 不会让 b 自动重算；最后一句才把当前 a 的 10 加到 b 上，得到 15。

变式：如果最后一句改为 `b = a + 3;`，b 就变成 13，因为它重新读取当前 a 并计算。两个写法只差一点，但一个基于 b 的旧值累加，一个直接按新的表达式覆盖。

### 第二层检查类型转换发生的时机

比较下面三个结果，要求输出一位小数：

```c
int total = 7;
int count = 2;

double a = total / count;
double b = (double)total / count;
double c = (double)(total / count);
```

答案依次为 3.0、3.5、3.0。b 在除法前转换，a 和 c 则都先完成了整数除法。变式：把 count 改成 4，三个结果依次变为 1.0、1.8、1.0；其中 b 内部结果为 1.75，按一位小数显示为 1.8。

### 第三层把现有规则迁移到新单位

把 3671 秒转换成小时、分钟和秒。可以先取完整小时，再对不足一小时的部分分解：

```c
int total_seconds = 3671;
int hours = total_seconds / 3600;
int remaining_seconds = total_seconds % 3600;
int minutes = remaining_seconds / 60;
int seconds = remaining_seconds % 60;
```

答案是 1 小时 1 分 11 秒。变式：改为 59 秒，得到 0 小时 0 分 59 秒；改为 3600 秒，得到 1 小时 0 分 0 秒。这里的基础是非负总秒数，若允许负时间，需要先重新规定输出含义。

### 第四层独立完成一个小需求

一本练习册单价 280 分，购买五本，预算 2000 分。请分别定义单价、数量、预算、总价和余额，用整数记录金额，再按前面的格式输出。

应得到总价 1400 分、余额 600 分，也就是 14.00 和 6.00。把数量改成六本后，总价变为 1680 分、余额变为 320 分，也就是 16.80 和 3.20。检查时既要看算术结果，也要看自己是否混用了“分”和“整单位”。

每次练习都可以重复同一个过程：先明确数据含义和单位，再选类型并初始化，按语句追踪状态，最后检查输出及边界。这样，后面遇到循环中的计数器、函数的参数或数组中的元素时，也能沿用“读取当前值、计算新值、写回目标对象”的思路。
