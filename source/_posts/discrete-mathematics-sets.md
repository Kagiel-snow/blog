集合这一部分，单看符号并不复杂，但做题时很容易把元素与子集、空集与只包含空集的集合混在一起。这篇先把对象和关系分清，再整理基本运算。后面学习关系、函数和图时，还会反复用到这些内容。

## 集合先看包含哪些元素

在入门阶段，可以把集合理解为由确定、互不相同的对象组成的整体，其中的对象称为元素。判断两个集合是否相等，依据是它们包含的元素是否完全相同。

例如：

```text
A = {1, 2, 3}
B = {3, 1, 2}
C = {1, 1, 2, 3}
```

这里 `A = B = C`。改变排列顺序不会得到新集合；把一个元素重复写出，也不会增加元素数量。因此 `|A| = 3`，竖线在这里表示集合的基数；对有限集合，就是元素个数。

集合与有序列表不同。列表 `[1, 2]` 和 `[2, 1]` 可以不同，但集合 `{1, 2}` 和 `{2, 1}` 相等。

另一种写法是描述元素满足的条件：

```text
A = {x ∈ ℤ | 1 ≤ x ≤ 3}
```

其中 `ℤ` 表示整数集，竖线在这里读作“使得”或“满足”，所以整个式子的意思是“所有满足 1 ≤ x ≤ 3 的整数 x 组成的集合”。它与上面的 `{1, 2, 3}` 相同。

注意同一个符号在不同位置的含义：`|A|` 表示基数，描述法中的 `|` 用来分隔对象与条件。条件也必须明确；“所有比较大的整数”如果没有说明多大，就不能据此确定元素。

## 属于与包含回答的是两个问题

| 写法 | 含义 | 判断方式 |
| --- | --- | --- |
| `x ∈ A` | x 是 A 的元素 | A 里面有没有 x 这个对象 |
| `x ∉ A` | x 不是 A 的元素 | A 里面没有 x 这个对象 |
| `A ⊆ B` | A 是 B 的子集 | A 的每个元素是否也在 B 中 |
| `A ⊊ B` | A 是 B 的真子集 | A 是 B 的子集，并且 A ≠ B |

有些教材用 `⊂` 表示真子集，有些用它表示允许相等的子集。这篇用 `⊆` 和 `⊊` 分开写，做题时仍以教材的约定为准。

设 `A = {1, 2, 3}`：

```text
1 ∈ A       成立
{1} ⊆ A     成立
{1} ∈ A     不成立
A ⊆ A       成立
A ⊊ A       不成立
```

`1` 是一个数，`{1}` 是一个集合。A 的三个元素都是数，里面没有把 `{1}` 这个集合单独列为元素，所以第三句不成立。

不过，“集合”也可以作为另一个集合的元素。再看：

```text
B = {1, {2}}

1 ∈ B       成立
{2} ∈ B     成立
2 ∈ B       不成立
{2} ⊆ B     不成立
```

B 的两个元素分别是 `1` 和 `{2}`。判断最后一句时，要检查 `{2}` 的唯一元素 `2` 是否属于 B；它不属于，所以子集关系不成立。括号的层次不能省略。

## 空集与包含空集的集合不同

空集记作 `∅`，它没有任何元素。`{∅}` 则有一个元素，这个元素恰好是空集。

```text
|∅| = 0
|{∅}| = 1
∅ ≠ {∅}
```

对于任意集合 A，都有 `∅ ⊆ A`。从子集的定义看，我们要检查空集中的每个元素是否都属于 A；空集没有元素，也就找不到违反这个要求的反例。这称为“空真”，之后学习逻辑中的全称命题时会再次遇到。

但 `∅ ∈ A` 并不总成立，它要求 A 确实把空集作为一个元素。

例如 `A = {1, 2}` 时，`∅ ⊆ A` 成立而 `∅ ∈ A` 不成立；`B = {∅, 1}` 时，两种关系都成立。

## 用同一组数据理解集合运算

设全集和两个集合为：

```text
U = {1, 2, 3, 4, 5, 6}
A = {1, 2, 3}
B = {3, 4, 5}
```

全集 U 表示当前讨论的范围。下面出现的补集都相对于这个 U。

| 运算 | 含义 | 结果 |
| --- | --- | --- |
| `A ∪ B` | 并集，属于 A 或属于 B | `{1, 2, 3, 4, 5}` |
| `A ∩ B` | 交集，同时属于 A 和 B | `{3}` |
| `A ∖ B` | 差集，属于 A 但不属于 B | `{1, 2}` |
| `B ∖ A` | 差集，属于 B 但不属于 A | `{4, 5}` |
| `Aᶜ = U ∖ A` | A 在 U 中的补集 | `{4, 5, 6}` |
| `A △ B` | 对称差，恰好属于 A、B 中的一个 | `{1, 2, 4, 5}` |

并集里的“或”允许两边同时成立。元素 3 同时属于 A 和 B，所以它属于并集，也属于交集；但不属于对称差。

差集通常不满足交换律：上面已经有 `A ∖ B ≠ B ∖ A`。补集则依赖全集；如果改成 `U = {1, 2, 3, 4}`，同一个 A 的补集就变成 `{4}`。

遇到复杂式子时，可以先翻译成元素需要满足的条件：

```text
x ∈ A ∪ B  ⇔  x ∈ A 或 x ∈ B
x ∈ A ∩ B  ⇔  x ∈ A 且 x ∈ B
x ∈ A ∖ B  ⇔  x ∈ A 且 x ∉ B
```

`⇔` 表示左右等价。这样写之后，集合运算就和逻辑中的“或”“且”“非”对应起来了。

## 常用运算规律怎样理解

先集中记住几组会经常使用的规律：

```text
交换律：A ∪ B = B ∪ A
        A ∩ B = B ∩ A

结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)
        (A ∩ B) ∩ C = A ∩ (B ∩ C)

分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
        A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

德摩根律：(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
          (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
```

这里所有补集使用同一个全集。第一条德摩根律可以读成：不属于 A 与 B 的并集，就是既不属于 A，也不属于 B。第二条则是：不能同时属于 A 和 B，等价于至少有一边不属于。

不必只按符号背诵。例如证明第一条分配律，取任意元素 x：

```text
x ∈ A ∩ (B ∪ C)
⇔ x ∈ A 且（x ∈ B 或 x ∈ C）
⇔（x ∈ A 且 x ∈ B）或（x ∈ A 且 x ∈ C）
⇔ x ∈ (A ∩ B) ∪ (A ∩ C)
```

任意 x 在等式左右两边的归属完全一致，因此两个集合相等。这是元素法。另一种常见写法是分别证明左右两边互为子集。

代入一组具体集合可以帮助理解，也可以用来寻找反例，但仅有一个例子吻合，不能证明对所有集合都成立。

## 幂集收集的是所有子集

A 的幂集记作 `𝒫(A)`，意思是“由 A 的全部子集组成的集合”。子集本身是幂集中的元素，注意又多了一层。

设 `A = {a, b}`：

```text
𝒫(A) = {∅, {a}, {b}, {a, b}}
```

四个子集分别对应：两个元素都不选、只选 a、只选 b、两个都选。

对于有 n 个元素的有限集合，每个元素都有选与不选两种情况，所以子集数量是 `2ⁿ`，即 `|𝒫(A)| = 2ⁿ`。有限性是这里的前提，不要直接把有限计数的解释套到无限集合上。

特别地：

```text
𝒫(∅) = {∅}
|𝒫(∅)| = 1 = 2⁰
```

空集的唯一子集是它自己，因此它的幂集并不为空。幂集和子集的定义可对照 [MIT 的集合课程讲义](https://courses.csail.mit.edu/6.042/spring15/sets.pdf)复习。

## 笛卡尔积中的顺序不能交换

设 `A = {1, 2}`、`B = {x, y}`，它们的笛卡尔积是：

```text
A × B = {(1, x), (1, y), (2, x), (2, y)}
```

其中的元素是有序对。`(1, x)` 和 `(x, 1)` 通常是不同对象，所以一般来说 `A × B ≠ B × A`。不要把有序对 `(1, x)` 写成没有顺序要求的集合 `{1, x}`。

若 A、B 都是有限集合，则 `|A × B| = |A| × |B|`。如果有一边为空，就无法组成有序对，因此 `A × ∅ = ∅`。

后面学习从 A 到 B 的二元关系时，会把关系定义为 `A × B` 的一个子集。现在先记住这一点：关系是在可能的有序对中，选出满足某种条件的那些对。

## 有限集合的计数不要重复计算

两个有限集合的并集满足：

```text
|A ∪ B| = |A| + |B| − |A ∩ B|
```

因为交集里的元素在 `|A| + |B|` 中算了两次，需要减去一次。

例如一个有 20 人的学习小组，12 人学习 C，9 人学习日语，其中 5 人两项都学。那么至少学习其中一项的人数为 `12 + 9 − 5 = 16`，两项都不学的人数为 `20 − 16 = 4`。这里默认讨论的是同一组人和同一统计时点。

如果题目问“只学 C”，结果是 `12 − 5 = 7`；如果问“恰好学一项”，结果是 `(12 − 5) + (9 − 5) = 11`。先判断自然语言对应哪一种集合运算，再计算。

## 复习时检查括号和对象层次

设 `S = {∅, 1, {2}}`，判断下列命题并计算基数：

1. `∅ ∈ S`
2. `{∅} ⊆ S`
3. `{2} ⊆ S`
4. `{{2}} ⊆ S`
5. `|S|` 与 `|𝒫(S)|` 分别是多少？

答案依次是：成立、成立、不成立、成立；`|S| = 3`，`|𝒫(S)| = 8`。

第三题检查的是数 2 是否在 S 中；第四题检查的是集合 `{2}` 是否在 S 中。两道题只差一层大括号，判断对象却不同。集合题出现犹豫时，先把外层集合的元素逐个列出来，再选择属于或包含关系。
