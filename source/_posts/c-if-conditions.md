变量存好以后，程序接下来要决定“什么情况下做什么”。最近的 C 语言练习主要就是把日语条件翻译成 if。先找出条件的边界和连接词，代码就容易写出来。

<!-- more -->

## a 大于等于 5

「a が 5 以上（いじょう）の場合（ばあい）」包含 5 本身，所以用 >=，不是 >。

```c
#include <stdio.h>

int main(void)
{
    int a = 7;
    if (a >= 5) {
        printf("%d は 5 以上\n", a);
    }
    return 0;
}
```

输出是 7 は 5 以上。这里的 %d 会被 a 的整数值替换。把 a 改成 5，条件仍成立；改成 4，就不进入大括号。

## a 与 b 不相等

不等价运算符是 !=。如果 a = 100、b = 50，a != b 成立。

```c
if (a != b) {
    printf("a and b are different\n");
} else {
    printf("a and b are equal\n");
}
```

需要特别区分：= 是赋值，== 是判断相等。if (a = 5) 会修改 a，而且赋值表达式的结果为 5，在条件中被当作真；这不是“判断 a 是否等于 5”。

## 两个数都小于 10

「両方（りょうほう）とも 10 より小（ちい）さい」中的“都”表示两个条件必须同时成立，用逻辑与 &&。

```c
if (a < 10 && b < 10) {
    printf("両方とも10より小さい\n");
}
```

不能写成 a < 10 < b。C 会先算 a < 10，得到 0 或 1，再把这个结果与 b 比较，含义已经变了。

| 日语条件 | 数学意思 | C 写法 |
| --- | --- | --- |
| 5以上 | 大于等于 5 | a >= 5 |
| 10未満（みまん） | 小于 10 | a < 10 |
| 等しくない | 不相等 | a != b |
| かつ | 同时满足 | && |
| または | 至少满足一个 | || |

## 用边界检查自己的理解

对于 a < 10 && b < 10，分别试 9 和 9、9 和 10、10 和 9。只有第一组成立。测试边界，比只看一组能通过的数据更容易发现符号写错。

补充一条：C 的条件判断把 0 看成假，非 0 看成真。比较运算的结果是 0 或 1。&& 与 || 有短路求值，而按位运算符 & 和 | 不能直接当成它们的替代品。
