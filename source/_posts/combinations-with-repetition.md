重复组合研究的是：从若干种可以区分的类型中，允许重复地选取一定数量，只按照每种类型选了多少来区分结果。例如从红、黄、白三种玫瑰中选七朵，如果只关心颜色数量，那么两朵红花、三朵黄花、两朵白花就是一种结果，拿取的先后顺序不会产生新的结果。

理解这类问题，需要把“选取顺序不计”“类型可以区分”和“每种数量可以为零”分开。隔板法能够把数量分配转化为位置选择，但使用之前，还必须检查总量、最低数量和最高数量的限制。这篇从符号开始，逐步推导计数方法，再应用到花束、整数方程、骰子与不相邻排列。

## 先看懂组合符号表示什么

组合在日语中称为「<span lang="ja" translate="no">組合せ・くみあわせ</span>」，英语是 combination。本文把“从 N 个不同对象中选择 r 个，不区分选择顺序”的数量记为 `C(N,r)`，日语教材也常写成 `ₙCᵣ`。上下排列、放在一对圆括号中的二项式系数，则是同一数量的另一种记法。

这类上下排列的记号不是分数，也不是把上面的数除以下面的数。例如 `C(6,3)` 表示从六个不同位置中选出三个位置，并不表示 `6 ÷ 3`。选位置 1、3、5，与按 5、1、3 的顺序选中它们，最终得到的仍然是同一组位置。

组合数的计算式是：

```text
C(N,r) = N! / (r!(N−r)!)

C(6,3) = 6! / (3!3!)
       = (6 × 5 × 4) / (3 × 2 × 1)
       = 20
```

这里的阶乘（<span lang="ja" translate="no">階乗・かいじょう</span> / factorial）表示从一个正整数连续乘到 1，例如 `3! = 3 × 2 × 1 = 6`，并规定 `0! = 1`。公式适用于整数 `0 ≤ r ≤ N`，其中分母的 r! 用来消除同一组对象内部的重复顺序。

选出 r 个对象，也就同时确定了没有选中的 N−r 个对象，所以 `C(N,r) = C(N,N−r)`。例如 `C(9,2) = C(9,7)`，可以解释为选出两块隔板的位置，也可以解释为选出七颗星的位置；只要整体模型相同，两种数法得到的是同一批结果。

## 重复组合只记录各类型的数量

重复组合的日语是「<span lang="ja" translate="no">重複組合せ・ちょうふくくみあわせ</span>」，英语常用 combinations with repetition，也可以称为 multiset combinations。这里的“重复”表示同一种类型可以选取多次，并不表示同一个物理对象可以被拿走两次。

设有红、黄、白三种玫瑰，每种供应充足，一共选择三朵。如果只比较颜色数量，那么 RRY、RYR、YRR 都表示“两红一黄”，因此只算一种。若把花插在三个有区别的位置上，并要求区分插放顺序，问题就改变了，不能继续按重复组合计数。

将三种颜色的数量分别记为 r、y、w，三朵花的十种选择可以完整列成：

| 红花 r | 黄花 y | 白花 w | 颜色构成 |
| --- | --- | --- | --- |
| 3 | 0 | 0 | 全红 |
| 0 | 3 | 0 | 全黄 |
| 0 | 0 | 3 | 全白 |
| 2 | 1 | 0 | 两红一黄 |
| 2 | 0 | 1 | 两红一白 |
| 1 | 2 | 0 | 一红两黄 |
| 0 | 2 | 1 | 两黄一白 |
| 1 | 0 | 2 | 一红两白 |
| 0 | 1 | 2 | 一黄两白 |
| 1 | 1 | 1 | 三色各一 |

表中每一行都满足 `r + y + w = 3`，且三个数量都是非负整数。因此，“三种颜色中重复选三朵”的问题，也可以写成求这个方程的非负整数解的数量。

这里的类型有固定名称，所以 `(r,y,w) = (2,1,0)` 与 `(1,2,0)` 是两种不同结果。前者选了两朵红花，后者选了两朵黄花；不区分拿花的先后，并不意味着红、黄、白可以随意互换。

## 分清四种计数模型

判断题目时，先确认顺序（<span lang="ja" translate="no">順序・じゅんじょ</span> / order）是否有意义，再确认是否允许重复使用同一类型。

| 模型 | 顺序是否有意义 | 是否允许重复 | 基本计数 |
| --- | --- | --- | --- |
| 排列，<span lang="ja" translate="no">順列</span> / permutation | 有 | 不允许 | `P(n,k) = n!/(n−k)!` |
| 重复排列，<span lang="ja" translate="no">重複順列</span> / ordered selections with repetition | 有 | 允许 | `nᵏ` |
| 组合，<span lang="ja" translate="no">組合せ</span> / combination | 无 | 不允许 | `C(n,k)` |
| 重复组合，<span lang="ja" translate="no">重複組合せ</span> / combinations with repetition | 无 | 允许 | `C(n+k−1,k)` |

例如从 A、B、C 三种字母中填三个有区别的位置，允许重复，每个位置都有三种选择，所以共有 `3³ = 27` 个字符串。如果只记录三个字母分别用了几个，ABC、ACB 等顺序就会合并，结果只有十种数量构成。

不能直接把 27 除以 3! 来得到重复组合数，因为不同数量构成对应的字符串数并不相同。AAA 只有一种顺序，AAB 有三种顺序，ABC 有六种顺序，没有一个共同的重复次数可以统一除去。

另一种容易混淆的题目是“把 A、A、A、B、B、C 六个符号排列”。它事先固定了每种符号的数量，要求计算排列顺序，答案是 `6!/(3!2!1!) = 60`。这种固定重复数量的排列，与让各类型数量自由变化的重复组合，是两个不同模型。

## 星与隔板怎样表示数量分配

隔板法的英语名称是 stars and bars，也就是“星与隔板”。星表示待分配的相同单位，隔板把它们分成若干段，各段按固定顺序对应不同类型。

仍然使用红、黄、白三种颜色，并且固定从左到右依次表示红、黄、白。三朵花画成三颗相同的星，把它们分成三段，需要两块隔板：

```text
红 | 黄 | 白

**|*|   → (r,y,w) = (2,1,0)
|***|   → (r,y,w) = (0,3,0)
*||**   → (r,y,w) = (1,0,2)
```

隔板放在最前面，表示第一种数量为零；放在最后面，表示最后一种数量为零；两块隔板相邻，表示中间一段数量为零。这些都允许，是因为目前的数量条件是非负整数，可以取 0。

三颗星和两块隔板一共有五个符号位置。只需从五个位置中选择两个放隔板，其余位置自然全部放星，因此数量为 `C(5,2) = 10`，与前面完整列举的十种结果一致。

这种计数成立的关键，是数量向量与符号排列之间存在一一对应（<span lang="ja" translate="no">一対一対応</span> / one-to-one correspondence，也称 bijection）。给定每种数量，就能唯一写出固定类型顺序下的星与隔板；给定符号排列，也能唯一读回每种数量。因此，数符号排列既不会漏掉数量方案，也不会把同一方案多算。

隔板本身不需要编号。第一块隔板自然是最左侧的边界，第二块是其右侧的边界；交换两块相同隔板，不会得到新的分配方案。

## 重复组合公式来自总符号数

一般地，从 n 种可以区分的类型中，允许重复地选 k 个，只关心每种类型的数量。假设 `n ≥ 1`、`k ≥ 0`，并且没有额外的库存或数量限制，那么需要 k 颗星和 n−1 块隔板。

为什么隔板比类型少一块？因为两段之间只需一个边界，三段需要两个边界，n 段自然只需要 n−1 个边界。最左侧和最右侧已经由整行符号的两端确定，不需要再补两块板。

总符号数为 `k + n − 1`，选择其中 n−1 个位置放隔板，得到：

```text
重复组合数
= C(k+n−1,n−1)
= C(k+n−1,k)
= (k+n−1)! / (k!(n−1)!)
```

有些记号体系把它写成 `H(n,k)` 或 `ₙHₖ`，含义仍然是从 n 种类型中重复选择 k 个。复习时要先明确 n 是类型数，k 是选取总数，再代入公式。

从方程角度看，同一个公式计算的是：

```text
x₁ + x₂ + … + xₙ = k
x₁、x₂、…、xₙ 都是非负整数
```

其中每个 xᵢ 记录对应类型的数量，位置和类型名称固定。若 k 为 0，所有数量只能为 0，只有一种结果；若 n 为 1，唯一类型必须承担全部 k 个，也只有一种结果。公式分别给出 `C(n−1,n−1) = 1` 和 `C(k,0) = 1`，与实际含义一致。

## 花束是否要求每种颜色出现会改变答案

从三种颜色中选七朵，允许某种颜色不出现时，数量条件是 `r + y + w = 7`，且 `r,y,w ≥ 0`。七颗星与两块隔板共九个位置，因此有：

```text
C(7+3−1,3−1) = C(9,2)
             = (9 × 8) / 2
             = 36
```

如果要求每种颜色至少一朵，就变成 `r,y,w ≥ 1`。此时不能直接沿用允许零的模型，而应先给每种颜色保留一朵，共用去三朵，再分配剩下的四朵。

令 `r′ = r−1`、`y′ = y−1`、`w′ = w−1`，那么三个新变量都是非负整数，满足 `r′ + y′ + w′ = 4`。因此答案变为：

```text
C(4+3−1,3−1) = C(6,2) = 15
```

这里“至少”在日语中常写作「<span lang="ja" translate="no">少なくとも</span>」，英语是 at least；它与“恰好”（<span lang="ja" translate="no">ちょうど</span> / exactly）不同。每色至少一朵，仍然允许某种颜色多于一朵。

同样地，三种颜色选十二朵，不限制颜色数量时，有 `C(14,2) = 91` 种；如果十二朵中每色至少一朵，先保留三朵，再分配九朵，得到 `C(11,2) = 55` 种。总量相同，但是否允许某种数量为零，会直接影响答案。

## 正整数总和为十为什么只剩七颗自由的星

考虑下面的问题：

```text
a + b + c = 10
a、b、c 都是正整数
```

正整数（<span lang="ja" translate="no">正の整数・せいのせいすう</span> / positive integer）从 1 开始，不包含 0，所以 `a,b,c ≥ 1`。先为三个变量各保留一个单位，共保留三个，剩余自由分配的数量才是 `10 − 3 = 7`。

正式地，令 `x = a−1`、`y = b−1`、`z = c−1`，代入原式，得到：

```text
(x+1) + (y+1) + (z+1) = 10
x + y + z = 7
x,y,z ≥ 0
```

这七颗星表示额外分配量，不是原来的全部十个单位。例如 `**|***|**` 对应 `(x,y,z) = (2,3,2)`，加回各自预留的一个后，才得到 `(a,b,c) = (3,4,3)`，总和仍然是 10。

![从三个变量各保留一个单位后，用七颗星和两块隔板表示剩余分配，再加回预留量](/img/notes/repetition-stars-and-bars.svg)

如果写成 `***||****`，额外分配量是 `(3,0,4)`，恢复后是 `(4,1,5)`。隔板相邻只说明新的 y 为零，并不意味着原来的 b 为零；原来的 b 已经保留了一个，仍满足正整数条件。

七颗星和两块隔板共有九个符号位置，因此：

```text
解的数量 = C(7+3−1,3−1)
         = C(9,2)
         = 36
```

这里不是 `C(7,2)`，因为选择的是九个总符号位置中的隔板位置，而不是从七颗星中选两颗。也不是 `C(10,3)`，因为问题在分配总量，不是在十个不同对象中抽出三个对象。

## 保留十颗星也能得到同一个答案

另一种数法可以直接保留十颗星，但要求三段都非空。此时隔板不能放在最前或最后，两块隔板也不能挨在一起，而必须占据星与星之间两个不同的内部缝隙。

```text
* _ * _ * _ * _ * _ * _ * _ * _ * _ *

10颗星之间共有9个内部缝隙。
选其中2个缝隙，就把10颗星分成3个非空部分。
```

例如选择第三颗星之后和第七颗星之后的缝隙，会得到 `***|****|***`，对应 `(a,b,c) = (3,4,3)`。所以仍然是 `C(9,2) = 36`。

两种方法的“九”具有不同来源：先保留最低数量后，九是七颗星加两块隔板的总位置数；直接使用十颗星时，九是十颗星之间的内部缝隙数。二者结果相同，但不能把一种方法的星数与另一种方法的隔板规则混在一起。

还可以用逐项列举核对。固定 a 为 1 时，b+c 为 9，有八组正整数解；a 为 2 时有七组，依次递减，a 最大到 8 时只剩 `(b,c) = (1,1)`。因此总数为 `8+7+6+5+4+3+2+1 = 36`。

如果原题改为允许 a、b、c 为零，则不需要先保留三个单位，应使用十颗星和两块可以相邻的隔板，答案是 `C(12,2) = 66`。36 与 66 的差异，完全来自“正整数”和“非负整数”这一个条件。

## 下限不同时先扣除各自必须承担的数量

一般的正整数方程 `x₁ + … + xₙ = k` 中，每个变量至少为 1。先保留 n 个单位，再使用非负整数公式，得到：

```text
k ≥ n 时：解数 = C(k−1,n−1)
k < n 时：解数 = 0
```

第二种情况不能忽略，因为 n 个正整数的总和至少是 n；例如三个正整数的和不可能等于 2。

若各变量的最低数量不同，例如 `a+b+c = 10`，并规定 `a ≥ 2`、`b ≥ 1`、`c ≥ 3`，就分别令 `x=a−2`、`y=b−1`、`z=c−3`。最低数量合计为六，剩余四个单位自由分配，所以答案为 `C(6,2) = 15`。

更一般地，n 个整数变量分别满足整数下限 `xᵢ ≥ Lᵢ`，总和为 k。把最低数量相加记为 L，再令 `yᵢ=xᵢ−Lᵢ`，就得到 n 个非负整数总和为 k−L 的问题；当 `k ≥ L` 时有 `C(k−L+n−1,n−1)` 个解，否则没有解。

这种变换只处理下限。若变量还有上限，仍需额外检查超出上限的解。

## 三个可区分骰子的点数和为八

假设有大、中、小三颗六面骰子，分别用 x、y、z 记录点数。由于骰子可以区分，`(1,2,5)` 与 `(2,1,5)` 是两个不同结果，不能只按三种点数的无序组合计算。

点数满足 `x+y+z = 8`，并且 `1 ≤ x,y,z ≤ 6`。先只考虑最低值 1，正整数解的数量是：

```text
C(8−1,3−1) = C(7,2) = 21
```

接着必须检查有没有被公式算进去、却不可能由骰子产生的值。如果某个变量至少为 7，另两个至少为 1，总和至少为 `7+1+1 = 9`，已经超过 8。因此本题的所有正整数解都会自动满足上限 6，不需要扣除，答案就是 21。

这道题之所以能直接用正整数公式，是因为已证明上限不会被突破，而不是因为隔板法会自动识别骰子的点数范围。

## 总和不超过八时引入一个剩余变量

若改为求三个骰子的点数和不超过 8，条件就变成 `x+y+z ≤ 8`。日语中的「<span lang="ja" translate="no">8以下・はちいか</span>」包括 8，而「<span lang="ja" translate="no">8未満・はちみまん</span>」不包括 8。

可以按总和从 3 到 8 分类，每一种总和的结果数分别为 1、3、6、10、15、21，相加得到 56。各类别按点数和区分，不会重叠，因此可以直接相加。

更通用的方法是引入一个非负的剩余变量 w，定义 `w = 8−(x+y+z)`，这样不等式就变成 `x+y+z+w = 8`。w 称为松弛变量，英语是 slack variable，日语可称「<span lang="ja" translate="no">スラック変数</span>」。

三个骰子至少为 1，但 w 可以为 0，所以只从 x、y、z 中各减去 1。令 `a=x−1`、`b=y−1`、`c=z−1`，得到：

```text
a + b + c + w = 5
a,b,c,w ≥ 0

结果数 = C(5+4−1,4−1)
       = C(8,3)
       = 56
```

w 不是第四颗骰子，也不是一次额外选择；它由前三颗骰子的点数唯一确定，所以不会把同一个骰子结果重复计数。这里骰子的上限依旧自动满足，因为任意一颗达到 7 时，总和至少已经是 9。

对一般非负整数不等式 `x₁+…+xₙ ≤ k`，也可以增加一个非负剩余变量，转化为 n+1 个非负整数总和为 k，解数为 `C(k+n,n)`。这个公式仍然假设没有另外的上限限制。

## 四个骰子的总和为十必须扣除上界之外的解

对于四颗可以区分的六面骰子，令点数为 x₁、x₂、x₃、x₄，要求总和为 10。先忽略最大点数 6，只看四个正整数的和，得到：

```text
C(10−1,4−1) = C(9,3) = 84
```

这次会出现不合法的正整数解，例如 `(7,1,1,1)`。因为四颗骰子可以区分，7 可以出现在四个位置，所以共有四个这样的不合法结果。

不可能再出现 8，因为 `8+1+1+1 = 11` 已经超出总和；也不可能有两颗同时达到 7。因此需要扣除的恰好就是这四个结果：

```text
合法结果数 = 84 − 4 = 80
```

当总量更大时，可能同时有多个变量越界，不能把每个越界类别直接相减就结束，因为那些同时越界的结果会被重复扣除。此时需要使用容斥原理（<span lang="ja" translate="no">包除原理・ほうじょげんり</span> / inclusion–exclusion principle），或者改用分情况、递推等方法。

以上骰子题计算的是结果数量，不是概率。只有进一步假设骰子公平且彼此独立，所有有序结果才等可能，才能分别除以 `6³` 或 `6⁴` 来求相应概率。

## 女生不相邻时要区分选空隙和安排具体人员

设五名男生、三名女生共八人，每个人都不同，排成一列，要求任意两名女生不相邻。这与重复组合中的隔板排列不同，但同样需要先看清边界和位置。

先安排五名男生，有 `5! = 120` 种顺序。每一种男生顺序都会产生六个可放女生的空隙，包括队列两端：

```text
空隙1 男1 空隙2 男2 空隙3 男3 空隙4 男4 空隙5 男5 空隙6
```

为了让女生两两不相邻，每个空隙最多放一名女生，所以先从六个不同空隙中选三个，有 `C(6,3) = 20` 种选法。再把三名不同女生安排进这三个位置，有 `3! = 6` 种顺序，因此完整答案是：

```text
5! × C(6,3) × 3!
= 120 × 20 × 6
= 14400
```

这里的 20 只完成了选空隙这一步；如果题目只区分男、女两种符号，不区分具体人员，那么 20 才是全部性别排列模式的数量。条件不同，不能把同一个中间结果直接作为两种题目的最终答案。

隔板法允许隔板相邻，是为了表示某种数量为零；这道题要求女生不能相邻，使用的是每个男生空隙最多放一人的限制。两者虽然都画出了空隙，但位置规则并不相同。

## 同一个公式还会以别的样子出现

重复组合数 `C(n+k−1,k)`，也就是前面提到的 `ₙHₖ`，在日本高中教材中很常见。熟悉了数量分配的模型之后，有几类题目看起来与选花无关，其实都可以翻译回“n 种类型中重复选 k 个”。

**非递减数列。** 满足 `1 ≤ x₁ ≤ x₂ ≤ x₃ ≤ 5` 的整数组 `(x₁,x₂,x₃)` 有多少个？只要决定 1～5 各出现几次，从小到大排好的数列就唯一确定，所以这是从五种数值中重复选三个，答案为 `C(5+3−1,3) = C(7,3) = 35`。如果条件改成严格递增 `x₁ < x₂ < x₃`，每个值最多用一次，就退回普通组合 `C(5,3) = 10`。

**多项式展开的项数。** `(a+b+c)⁶` 展开并合并同类项后有多少项？每一项都形如 `aᵖbᵠcʳ`，其中 `p+q+r = 6`，三个指数是非负整数。项数等于非负整数解的个数 `C(8,2) = 28`。这里求的是不同的项有多少种，不是系数之和；系数之和是把 a、b、c 都代入 1 得到的 `3⁶ = 729`。

**相同物品分给不同的人。** 把八个相同的苹果分给三个人，可以有人分不到，结果只由每人得到几个决定，答案是 `C(10,2) = 45`。如果八个物品各不相同，每个物品独立地决定交给谁，就变成重复排列 `3⁸ = 6561`。两者的区别在于物品是否可以区分，而不在于人是否可以区分。

| 物品 | 接收者 | 是否允许空 | 模型 | 例子（8 个物品，3 人） |
| --- | --- | --- | --- | --- |
| 相同 | 可区分 | 允许 | 重复组合 | `C(10,2) = 45` |
| 相同 | 可区分 | 每人至少一个 | 先各给一个，再重复组合 | `C(7,2) = 21` |
| 可区分 | 可区分 | 允许 | 重复排列 | `3⁸ = 6561` |

如果接收者也不可区分（比如把苹果分成三堆，堆没有名字），问题就变成整数分拆，不能直接套用隔板法。

**一条做题时的判断顺序。** 先问“结果由什么唯一确定”：如果由每种类型的数量确定，就是重复组合；如果由每个位置放了什么确定，就是排列类；然后再检查下限和上限。

## 用中日英完整表述一次解题过程

以 `a+b+c = 10` 的正整数解为例，中文可以表述为：因为三个变量都至少为 1，先从每个变量中扣除一个，得到三个非负整数总和为 7。将七个相同单位与两块隔板排列，从九个位置中选择两个作为隔板，因此共有 `C(9,2) = 36` 组解。

<div lang="ja" translate="no">

<p>a、b、c は正の整数なので、それぞれ少なくとも 1 である。x=a−1、y=b−1、z=c−1 とおくと、x、y、z は非負整数で、x+y+z=7 を満たす。7 個の同じ記号と 2 個の仕切りを並べると考えれば、9 個の位置から仕切りの位置を 2 個選ぶので、解は C(9,2)=36 通りある。</p>

</div>

<div lang="en" translate="no">

<p>Since a, b, and c are positive integers, each is at least 1. Let x=a−1, y=b−1, and z=c−1. Then x, y, and z are non-negative integers satisfying x+y+z=7. Using seven stars and two bars, we choose two of the nine symbol positions for the bars. Therefore, there are C(9,2)=36 solutions.</p>

</div>

三种表述采用的是同一条推理：先说明下限，再变换变量，接着建立星与隔板的一一对应，最后计算组合数。这样既能说明公式适用的原因，也能避免只留下一个没有依据的 36。

## 练习时先写变量条件再计算

1. 四种糖果中选六颗，各种供应充足，只关心每种数量，有多少种选择？
2. 三种颜色选七朵花，要求每色至少一朵，有多少种选择？
3. `a+b+c=10`，要求 `a≥2`、`b≥1`、`c≥3`，有多少组整数解？
4. 四个非负整数的总和不超过 5，有多少组解？
5. 四颗可区分六面骰子的点数和为 10，有多少个结果？
6. 五名不同男生和三名不同女生排成一列，女生两两不相邻，有多少种安排？
7. 满足 `1 ≤ x ≤ y ≤ z ≤ 6` 的整数组有多少个？
8. `(x+y+z+w)⁵` 展开后有多少个不同的项？

第一题是四种类型选六个的重复组合，答案为 `C(6+4−1,4−1) = C(9,3) = 84`。第二题先为三种颜色各保留一朵，剩余四朵自由分配，答案为 `C(6,2) = 15`。

第三题最低数量合计为六，把各自下限扣除后，三个非负整数总和为四，因此也是 `C(6,2) = 15`。第四题引入一个非负剩余变量，转化为五个非负整数总和为五，所以答案是 `C(9,4) = 126`。

第五题先数全部正整数解，得到 84，再扣除含一个 7、其余全为 1 的四个越界结果，答案为 80。第六题需要同时计算男生顺序、空隙选择和女生顺序，所以答案为 `5! × C(6,3) × 3! = 14400`。

第七题相当于从 1～6 中重复选三个，答案为 `C(8,3) = 56`。第八题求 `p+q+r+s = 5` 的非负整数解，答案为 `C(8,3) = 56`。两题数字相同只是巧合：前者是六种类型选三个，后者是四种类型选五个，`C(6+3−1,3)` 与 `C(4+5−1,5)` 恰好都等于 `C(8,3)`。

每道题的算式，都应当能回到变量或位置的实际含义。星的数量是自由分配的总量，隔板的数量由类型数决定，是否允许空段由最低数量决定，而最高数量的限制需要另行处理。把这些条件先写清楚，重复组合就可以从数量分配的定义一步步推导出来。
