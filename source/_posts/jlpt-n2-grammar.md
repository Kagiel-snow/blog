N2 的语法点数量多，而且很多条意思相近，只按五十音顺序背，到了考试时很难分清。这篇按功能把常考语法分组：同一组里的语法放在一起比较，看它们的接续有什么不同，语气、使用场合有什么区别。

接续记号：V 是动词，A 是い形容词，Na 是な形容词，N 是名词。「V る」是辞书形，「V た」是た形，「V ない」是ない形的词干加ない，「V ます」是ます形去掉ます的部分。「普通形」包括肯定、否定、过去。

## 一、时间与同时

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜うちに | V る／V ている／V ない／A い／Na な／N の | 趁着……；在……过程中（不知不觉） |
| 〜最中に | V ている／N の | 正在……的时候（突发事件打断） |
| 〜たとたん（に） | V た | 刚一……就（意外的事） |
| 〜次第 | V ます | 一……就立刻（说话人的意志行为） |
| 〜かと思うと／〜かと思ったら | V た | 刚……马上就（变化快） |
| 〜て以来 | V て | 自从……以来一直 |
| 〜につれて／〜にしたがって | V る／N | 随着…… |
| 〜にあたって／〜に際して | V る／N | 在……之际（正式） |

<div lang="ja" translate="no">

- 若いうちに、いろいろな国へ行っておきたい。
- 話しているうちに、だんだん眠くなってきた。
- 会議の最中に、電話が鳴った。
- ドアを開けたとたん、猫が飛び出してきた。
- 結果がわかり次第、ご連絡いたします。
- 泣いていたかと思うと、もう笑っている。
- 日本に来て以来、ずっとこのアパートに住んでいる。
- 年をとるにつれて、記憶力が落ちてきた。
- 開会にあたって、一言ご挨拶申し上げます。

</div>

**辨析**

- 「<span lang="ja" translate="no">たとたん</span>」和「<span lang="ja" translate="no">次第</span>」都是“一……就”。「<span lang="ja" translate="no">たとたん</span>」后面是已经发生的、意外的事，不能接说话人的意志；「<span lang="ja" translate="no">次第</span>」后面是说话人将要做的事，常用于商务。
  - × <span lang="ja" translate="no">家に着いたとたん、電話します。</span>
  - ○ <span lang="ja" translate="no">家に着き次第、電話します。</span>
- 「<span lang="ja" translate="no">うちに</span>」强调“趁状态还没改变”，前面常是会变的状态（年轻、热、还没下雨）。「<span lang="ja" translate="no">間に</span>」只是表示一段时间内。

## 二、原因与理由

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜おかげで | 普通形（Na な／N の） | 多亏了……（好结果） |
| 〜せいで／〜せいか | 普通形（Na な／N の） | 都怪……（坏结果）；也许是因为…… |
| 〜ため（に） | 普通形（Na な／N の） | 因为（书面） |
| 〜ことから | 普通形（Na な・である／N である） | 从……来看（判断依据或命名由来） |
| 〜ものだから／〜もので | 普通形（Na な／N な） | 因为（辩解） |
| 〜あまり | V る／V た／Na な／N の | 由于过于…… |
| 〜以上（は） | 普通形（N である） | 既然……就 |
| 〜上は | V る／V た | 既然……就（更正式） |
| 〜からには | 普通形 | 既然……就一定 |
| 〜だけに | 普通形（Na な／N） | 正因为……所以更加 |

<div lang="ja" translate="no">

- 先生のおかげで、合格できました。
- 雨のせいで、試合が中止になった。
- 寝不足のせいか、頭が痛い。
- 足跡が残っていることから、犯人は窓から入ったと考えられる。
- 道が混んでいたものですから、遅くなってしまいました。
- 緊張のあまり、名前を言い間違えた。
- 約束した以上、守らなければならない。
- 引き受けたからには、最後までやります。
- 期待していただけに、がっかりした。

</div>

**辨析**

- 「<span lang="ja" translate="no">以上</span>」「<span lang="ja" translate="no">からには</span>」「<span lang="ja" translate="no">上は</span>」意思相同，后面都接说话人的决心、义务或劝告（〜べきだ、〜なければならない、〜つもりだ）。
- 「<span lang="ja" translate="no">ものだから</span>」是在解释自己为什么这样做，带辩解的语气，不用于正式的书面说明。
- 「<span lang="ja" translate="no">だけに</span>」表示“正因为有这个前提，结果的程度更深”，前后有比例关系；结果可好可坏。

## 三、条件与假设

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜さえ〜ば | N さえ V ば／V ます さえ すれば | 只要……就 |
| 〜ない限り | V ない | 只要不……就（不会） |
| 〜限り（は） | V る／V ている／N である | 只要……（状态持续） |
| 〜としたら／〜とすれば | 普通形 | 假如……的话 |
| 〜ものなら | V 可能形 る | 如果能……的话（几乎不可能） |
| 〜ようものなら | V 意向形 | 万一……的话（就会有坏结果） |
| 〜次第で | N | 根据……而定 |
| 〜を抜きにしては | N | 如果撇开……就（无法） |

<div lang="ja" translate="no">

- 時間さえあれば、もっと旅行したい。
- 薬を飲みさえすれば、すぐ治ります。
- 努力しない限り、成功はない。
- 私が社長である限り、この方針は変えない。
- 宝くじが当たったとしたら、何に使いますか。
- できるものなら、もう一度学生時代に戻りたい。
- 遅刻しようものなら、先生にひどく叱られる。
- 結果次第で、計画を変えることもある。

</div>

**辨析**：「<span lang="ja" translate="no">ものなら</span>」接可能形，表示实现的可能性很低的愿望；「<span lang="ja" translate="no">ようものなら</span>」接意向形，表示“一旦做了就会招致严重后果”。

## 四、逆接与让步

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜にもかかわらず | 普通形（Na である／N） | 尽管……却 |
| 〜ものの | 普通形（Na な・である） | 虽然……但是 |
| 〜くせに | 普通形（Na な／N の） | 明明……却（责备） |
| 〜わりに（は） | 普通形（Na な／N の） | 与……相比，出乎意料地 |
| 〜といっても | 普通形 | 虽说……其实 |
| 〜からといって | 普通形 | 不能因为……就 |
| 〜にしても／〜にせよ | 普通形（N） | 即使……也 |
| 〜ところで | V た | 即使……也（没用） |
| 〜つつ（も） | V ます | 虽然……还是 |

<div lang="ja" translate="no">

- 雨にもかかわらず、多くの人が集まった。
- 免許は取ったものの、ほとんど運転していない。
- 知っているくせに、教えてくれない。
- このレストランは値段のわりに、おいしい。
- 料理ができるといっても、簡単なものだけです。
- 日本人だからといって、敬語が完璧なわけではない。
- 今から急いだところで、間に合わないだろう。
- 体に悪いと知りつつも、タバコをやめられない。

</div>

**辨析**

- 「<span lang="ja" translate="no">くせに</span>」带强烈的责备或轻蔑，主语通常是别人，前后主语相同。
- 「<span lang="ja" translate="no">ものの</span>」是书面，前项是承认的事实，后项是与预期不符的情况。
- 「<span lang="ja" translate="no">からといって</span>」后面常接部分否定「〜わけではない」「〜とは限らない」。
- 「<span lang="ja" translate="no">ところで</span>」接た形，后面是否定或消极的判断。注意和话题转换的接续词「<span lang="ja" translate="no">ところで</span>」区分。

## 五、程度与限度

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜ほど／〜くらい | 普通形（Na な／N） | 到……的程度 |
| 〜ほど〜はない | N | 没有比……更…… |
| 〜ば〜ほど | V ば V る | 越……越 |
| 〜ばかりか／〜ばかりでなく | 普通形（Na な／N） | 不仅……而且 |
| 〜どころか | 普通形（Na／N） | 别说……反而／连……都不 |
| 〜に限る | V る／V ない／N | ……最好 |
| 〜に過ぎない | 普通形（N） | 只不过是 |
| 〜てたまらない／〜てならない | V て／A くて／Na で | ……得受不了 |
| 〜てしょうがない | V て／A くて／Na で | ……得不得了（口语） |

<div lang="ja" translate="no">

- 立っていられないほど疲れた。
- 健康ほど大切なものはない。
- 練習すればするほど上手になる。
- 彼は英語ばかりか、中国語も話せる。
- 休むどころか、食事をする時間もない。
- 暑い日は冷たいビールに限る。
- それは私の個人的な意見に過ぎません。
- 試験の結果が気になってたまらない。

</div>

**辨析**：「<span lang="ja" translate="no">どころか</span>」有两个用法：前后程度递进（不仅……甚至……），或前后方向相反（不但没……反而……）。「<span lang="ja" translate="no">雨は止むどころか、ますます激しくなった。</span>」（雨不但没停，反而更大了。）

「<span lang="ja" translate="no">てならない</span>」多用于自发产生的情绪和感觉（気がする、思える、心配だ），比「<span lang="ja" translate="no">てたまらない</span>」更书面。

## 六、立场、观点与对象

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜にとって | N | 对……来说（评价的立场） |
| 〜に対して | N | 对于……（行为的对象）；与……相对 |
| 〜について／〜に関して | N | 关于 |
| 〜として | N | 作为 |
| 〜からすると／〜からすれば | N | 从……的立场看 |
| 〜から見ると | N | 从……来看 |
| 〜にしては | 普通形（N） | 作为……来说（与预期不符） |
| 〜わりには | 普通形（Na な／N の） | 与……相比 |
| 〜をめぐって | N | 围绕……（争论） |
| 〜をはじめ（として） | N | 以……为首 |
| 〜に応じて | N | 根据……（相应变化） |
| 〜に基づいて | N | 基于…… |
| 〜を通じて／〜を通して | N | 通过……；在整个……期间 |

<div lang="ja" translate="no">

- 私にとって、家族が一番大切だ。
- 先生に対して、失礼なことを言ってはいけない。
- 留学生として、日本に来ました。
- 親からすれば、子どもはいつまでも子どもだ。
- 彼は初心者にしては、上手だ。
- 新しい法律をめぐって、議論が続いている。
- 収入に応じて、税金が決まる。
- 事実に基づいて、報告書を書く。
- この地域は一年を通じて暖かい。

</div>

**辨析**

- 「<span lang="ja" translate="no">にとって</span>」后面接评价（重要、难、方便），不能接动作；「<span lang="ja" translate="no">に対して</span>」后面接针对对象的行为或态度。
  - × <span lang="ja" translate="no">私にとって、彼は親切にしてくれた。</span>
  - ○ <span lang="ja" translate="no">彼は私に対して親切だ。</span>
- 「<span lang="ja" translate="no">にしては</span>」的前项是具体的人或事，后面与该人事通常的水平不符；「<span lang="ja" translate="no">わりには</span>」前面常是程度性的词（年齢、値段）。

## 七、强调与限定

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜こそ | N／V て | 正是……才 |
| 〜さえ／〜すら | N | 连……都 |
| 〜に限って | N | 偏偏……；唯独……不会 |
| 〜ばかり | N／V て | 光是、净是 |
| 〜だけあって | 普通形（Na な／N） | 不愧是……（褒义） |
| 〜ならでは | N | ……特有的、只有……才有 |
| 〜に限らず | N | 不仅限于 |
| 〜のみならず | 普通形（N） | 不仅……（书面） |
| 〜もかまわず | N | 不顾…… |

<div lang="ja" translate="no">

- 今年こそ、N2 に合格したい。
- 忙しくて、寝る時間さえない。
- 急いでいる日に限って、電車が遅れる。
- うちの子に限って、そんなことをするはずがない。
- さすがプロだけあって、料理が本当においしい。
- これは京都ならではの景色だ。
- この問題は若者に限らず、高齢者にも関係がある。
- 人目もかまわず、大声で泣いた。

</div>

## 八、判断、推测与评价

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜わけだ | 普通形（Na な／N の・である） | 怪不得、当然 |
| 〜わけがない | 普通形（Na な／N の・である） | 不可能 |
| 〜わけではない | 普通形（Na な／N の・である） | 并不是 |
| 〜わけにはいかない | V る／V ない | 不能（由于道理或情理） |
| 〜に違いない／〜に相違ない | 普通形（Na／N） | 一定是 |
| 〜おそれがある | V る／N の | 有……的危险（坏事） |
| 〜かねない | V ます | 很可能会（坏结果） |
| 〜かねる | V ます | 难以……（委婉拒绝） |
| 〜っこない | V ます | 不可能（口语） |
| 〜とは限らない | 普通形 | 未必 |
| 〜ざるを得ない | V ない（する→せざる） | 不得不 |
| 〜ないことはない | V ない／A くない | 也不是不…… |
| 〜べきだ／〜べきではない | V る（する→すべき） | 应该／不应该 |

<div lang="ja" translate="no">

- 毎日練習しているから、上手なわけだ。
- こんな難しい問題、私にわかるわけがない。
- 肉が嫌いなわけではないが、あまり食べない。
- 明日は試験だから、遊びに行くわけにはいかない。
- 台風が上陸するおそれがある。
- そんな運転をしていたら、事故を起こしかねない。
- その件については、お答えしかねます。
- 高いものがいいものだとは限らない。
- 誰もやらないなら、私がやらざるを得ない。

</div>

**辨析**

- 「<span lang="ja" translate="no">かねない</span>」（会）和「<span lang="ja" translate="no">かねる</span>」（不能）形式上像肯定和否定，意思却正好相反，是 N2 最常考的陷阱之一。
- 「<span lang="ja" translate="no">おそれがある</span>」用于新闻、天气预报等客观的书面说明；「<span lang="ja" translate="no">かねない</span>」更带说话人的担心和批评。
- 「<span lang="ja" translate="no">わけにはいかない</span>」是由于社会常识或良心而不能做，不是能力上做不到。

## 九、倾向与状态

| 语法 | 接续 | 含义 |
| --- | --- | --- |
| 〜がち | V ます／N | 容易……、经常（坏的倾向） |
| 〜気味 | V ます／N | 有点……的感觉 |
| 〜っぽい | V ます／A／N | 像……、容易…… |
| 〜げ | A／Na | ……的样子（书面） |
| 〜一方だ | V る | 一直……下去（单方向变化） |
| 〜つつある | V ます | 正在逐渐…… |
| 〜きり | V た | ……之后就再也没有 |
| 〜っぱなし | V ます | 放着不管、一直保持 |

<div lang="ja" translate="no">

- 冬は運動不足になりがちだ。
- 最近、風邪気味で体がだるい。
- 彼は忘れっぽい。
- 物価は上がる一方だ。
- 景気は回復しつつある。
- 彼とは卒業して以来、一度会ったきりだ。
- 電気をつけっぱなしで出かけてしまった。

</div>

「<span lang="ja" translate="no">がち</span>」「<span lang="ja" translate="no">気味</span>」「<span lang="ja" translate="no">っぽい</span>」大多用于负面倾向。「<span lang="ja" translate="no">がち</span>」表示频率高，「<span lang="ja" translate="no">気味</span>」表示程度轻、有一点，「<span lang="ja" translate="no">っぽい</span>」口语化，范围最广（子どもっぽい、怒りっぽい、白っぽい）。

## 十、易混组速查

| 组 | 区别要点 |
| --- | --- |
| たとたん ／ 次第 | 意外的已发生事实 ／ 说话人的意志行为 |
| おかげで ／ せいで | 好结果 ／ 坏结果 |
| にとって ／ に対して | 评价的立场 ／ 行为的对象 |
| かねない ／ かねる | 可能会发生坏事 ／ 难以做到（拒绝） |
| わけがない ／ わけではない ／ わけにはいかない | 不可能 ／ 并不是 ／ 不能（情理上） |
| ものなら ／ ようものなら | 如果能（愿望） ／ 万一做了（坏后果） |
| くせに ／ のに | 带责备、轻蔑 ／ 一般的不满或遗憾 |
| がち ／ 気味 ／ っぽい | 频率高 ／ 有一点 ／ 带有性质（口语） |

## 练习

选择正确的一项：

1. 家に着き（　　）、メールします。　a. たとたん　b. 次第　c. うちに
2. 先生の（　　）、論文が完成しました。　a. せいで　b. おかげで　c. くせに
3. このままでは、大きな事故につながり（　　）。　a. かねない　b. かねる　c. わけがない
4. 留学生（　　）、日本の文化をもっと知りたい。　a. にとって　b. として　c. に対して
5. 彼は日本に 10 年住んでいる。日本語が上手な（　　）。　a. わけだ　b. わけではない　c. わけにはいかない
6. 親に反対された（　　）、留学をあきらめるつもりはない。　a. からといって　b. からには　c. 以上

**答案**

1. b。说话人将要做的意志行为，用「<span lang="ja" translate="no">次第</span>」。
2. b。好结果。
3. a。“有可能导致”。
4. b。表示身份、资格。
5. a。根据前提得出“怪不得”。
6. a。“不能因为……就……”，后面是否定的判断。
