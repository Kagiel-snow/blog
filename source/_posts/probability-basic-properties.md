概率的基本性质，可以从“所有结果是什么、关心哪些结果、怎样分配概率”这三个问题开始理解。只有先把试验和事件写清楚，后面的加法、减法以及情况数之比才有依据，不能仅凭结果看起来有几种就平均分配概率。

这篇接着此前关于「確率空間および確率の定義」的讨论，把样本空间、事件与概率连起来，再整理三枚硬币、三个骰子和抽球练习。集合符号和排列组合的基础，可以分别对照[集合笔记](/posts/discrete-mathematics-sets/)与[排列组合笔记](/posts/permutations-combinations/)复习。

## 试验结束后得到一个结果

随机试验（<span lang="ja" translate="no">試行・しこう</span> / random experiment）是结果带有不确定性的实验或观察。例如掷一次六面骰子，在落地前不知道会出现哪个点数，但可以先列出本模型中允许的全部结果。

全部基本结果组成的集合，叫作样本空间（<span lang="ja" translate="no">標本空間・ひょうほんくうかん</span> / sample space），通常记为 Ω。掷一次骰子的模型可以写成：

```text
Ω = {1, 2, 3, 4, 5, 6}
```

这里的 4 是一个结果，而“出现 4”这个事件可以写成集合 `{4}`。这一区分和此前集合笔记中“元素”与“只含这个元素的集合”相同；日语课件中的「<span lang="ja" translate="no">根元事象</span>」常用于描述这样的单一结果事件，阅读时要看清符号是在指结果还是事件。

如果同时掷三个可以区分的骰子，一个结果就需要记录三个位置，例如 `(1,2,3)`。它与 `(3,2,1)` 是不同结果，因为第一颗和第三颗骰子的点数不同。样本空间的元素必须与试验实际记录的信息一致，不能在计算途中突然把有序结果改成无序集合。

## 事件是我们关心的一组结果

事件（<span lang="ja" translate="no">事象・じしょう</span> / event）把满足某个条件的结果收集起来。例如在一次掷骰子的模型中，令 A 表示出现偶数，B 表示出现大于 4 的点数，就得到：

```text
A = {2, 4, 6}
B = {5, 6}
```

当实际结果属于 A 时，就说事件 A 发生；例如结果为 4 时 A 发生，结果为 5 时 A 不发生。单个事件可以包含多个结果，而一次试验在这个模型中仍然只产生一个基本结果。

事件之间的关系直接沿用集合运算，理解符号后才能决定概率应该怎么算：

| 记号 | 事件含义 | 上例中的结果 |
| --- | --- | --- |
| `A ∩ B` | A 和 B 同时发生 | `{6}` |
| `A ∪ B` | A 或 B 至少一个发生 | `{2,4,5,6}` |
| `Aᶜ` | A 不发生，也称补事件或余事件 | `{1,3,5}` |
| `A ∖ B` | A 发生且 B 不发生 | `{2,4}` |

补事件（<span lang="ja" translate="no">余事象・よじしょう</span> / complement）必须相对于同一个 Ω 来定义。并集中的“或”包含 A、B 同时发生，若题目要求“恰好其中一个发生”，就要另外排除交集。

Ω 本身作为事件，叫作全事件（<span lang="ja" translate="no">全事象</span>），在模型中必然发生。空集 ∅ 对应空事件（<span lang="ja" translate="no">空事象</span>），没有任何结果能使它发生，例如普通六面骰子出现 7。

## 概率空间把结果和概率规则放在一起

完整的概率空间（<span lang="ja" translate="no">確率空間</span> / probability space）写成 `(Ω, ℱ, P)`。Ω 描述全部基本结果，ℱ 是可以赋予概率的事件组成的集合族，P 则把每个事件映射到一个概率数值。

在本文使用的有限模型中，可以取 ℱ 为 Ω 的所有子集，也就是幂集 `𝒫(Ω)`，有的教材写作 `2^Ω`。例如抛一枚硬币，用 H 表示正面、T 表示反面，那么：

```text
Ω = {H,T}
ℱ = {∅, {H}, {T}, {H,T}}
```

Ω 的元素是结果，ℱ 的元素是事件，它们处于不同层次。P 接收的是一个事件，例如 `P({H})`，并返回它发生的概率；若规定硬币公平，就设置 `P({H}) = P({T}) = 1/2`。

一般的无限模型中，ℱ 要满足 σ 代数的条件，即包含 Ω，并对补集和可数并封闭，不一定能直接选成所有子集。初学时不需要立即展开测度论，但应记住本文“每个子集都可作为事件”的做法依赖这里选用的有限模型。

## 三条公理规定概率如何分配

概率测度 P 满足三项基本要求：每个事件的概率非负，整个样本空间的概率等于 1，以及互不重叠的事件可以相加。

更完整地说，第三项是可数可加性：如果 A₁、A₂、……两两互不重叠，那么它们并集的概率等于各自概率之和。本文的有限例题使用它的有限形式：

```text
非负性：P(A) ≥ 0
规范性：P(Ω) = 1

若 A ∩ B = ∅，则：
P(A ∪ B) = P(A) + P(B)
```

两事件交集为空时，称为互斥事件，日语为「<span lang="ja" translate="no">排反事象・はいはんじしょう</span>」。例如一次掷骰子中，出现 1 与出现 2 不可能同时成立，因此这两个事件互斥；如果骰子公平，它们并集的概率是 `1/6 + 1/6 = 1/3`。

“骰子公平”是赋予每个点数相同概率的建模条件，三条公理本身并没有规定所有点数必须一样可能。一个有偏骰子仍可以满足公理，只是各点数的概率不同。基本术语和例子也可以对照 [MIT 的概率基础阅读材料](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/classes-reading-and-in-class-materials/)复习。

## 空事件和补事件的公式可以推出来

空事件与 Ω 互不重叠，而且并集仍然是 Ω，因此可加性给出 `P(Ω) = P(Ω) + P(∅)`。两侧减去 `P(Ω)`，就得到 `P(∅) = 0`。

对于任意事件 A，A 与 Aᶜ 互不重叠，而且它们的并集正好是 Ω，因此：

```text
P(A) + P(Aᶜ) = P(Ω) = 1
P(Aᶜ) = 1 − P(A)
```

因为补事件的概率不能为负，所以 `1 − P(A) ≥ 0`，结合非负性就得到 `0 ≤ P(A) ≤ 1`。因此，概率范围不是额外随意规定出来的结论，而是可以由公理与事件关系推导得到。

在公平骰子中，出现偶数的概率是 1/2，不出现偶数的概率也是 `1 − 1/2 = 1/2`。补事件公式的用途在于：当直接计数 A 很复杂，但 Aᶜ 很简单时，可以先计算后者。

## 加法公式为什么需要减去交集

若 A、B 可能同时发生，直接计算 `P(A) + P(B)` 会把交集中的结果算两次。并集只应包含每个结果一次，因此一般的加法公式是：

```text
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
```

仍用 `A = {2,4,6}`、`B = {5,6}` 的公平骰子例子，A 有三个结果，B 有两个结果，但 6 同时属于二者，所以：

```text
P(A ∪ B) = 3/6 + 2/6 − 1/6
         = 4/6
         = 2/3
```

如果 A、B 互斥，交集就是空事件，其概率为 0，这个公式才退化成直接相加。做题时，应先检查交集，不能把所有含“或”的题都写成两个概率相加。

若要求恰好 A、B 中一个发生，就要把交集全部去掉。其概率是 `P(A) + P(B) − 2P(A ∩ B)`；在这个骰子例子中，对应 `{2,4,5}`，概率是 1/2。

## 包含关系给出单调性和概率界限

如果 `A ⊆ B`，A 发生时 B 必然也发生，因此 A 的概率不会超过 B。可以把 B 拆成互不重叠的 A 和 `B ∖ A`，从而得到：

```text
P(B) = P(A) + P(B ∖ A)
P(A) ≤ P(B)
P(B ∖ A) = P(B) − P(A)
```

这就是概率的单调性。差事件的最后一个公式需要 `A ⊆ B`，否则减去 P(A) 可能还减掉不属于 B 的部分；一般的 `P(A ∖ B)` 应写成 `P(A) − P(A ∩ B)`。

交集包含在 A 和 B 中，因此 `P(A ∩ B) ≤ min(P(A),P(B))`。并集包含 A 和 B，因此 `P(A ∪ B) ≥ max(P(A),P(B))`；再结合加法公式与交集非负，可以得到 `P(A ∪ B) ≤ P(A) + P(B)`，也就是两事件的并集上界。

这些性质可以用来快速检查答案。例如题目给出 `P(A) = 0.7`、`P(B) = 0.6` 时，交集至少要有 0.3，否则并集的概率就会超过 1。一般地：

```text
max(0, P(A)+P(B)−1) ≤ P(A ∩ B) ≤ min(P(A),P(B))
```

## 情况数之比需要有限和等可能的前提

在有限样本空间中，若每个基本结果都同样可能（<span lang="ja" translate="no">同様に確からしい</span> / equally likely），就可以使用古典概率：

```text
P(A) = |A| / |Ω|
```

竖线表示有限集合的元素个数，分子是满足事件 A 的结果数，分母是全部结果数。因为每个结果的概率相同，而全部概率之和是 1，所以每个基本结果占 `1/|Ω|`，事件的概率才等于这种计数比例。

例如公平骰子中偶数占六个结果中的三个，所以概率是 3/6。但若骰子有偏，就需要把 2、4、6 对应的概率相加，不能因为它们依旧占一半的点数，就认定概率为 1/2。

掷两颗公平且独立的骰子时，有序点数对可以视为等可能结果；但点数和 2～12 并不等可能。和为 2 只有 `(1,1)`，和为 7 却有六个有序结果，所以不能把十一种点数和平均分成十一份。

## 三颗骰子的点数和为 5

假设三颗骰子可以区分、公平且相互独立，那么第一、第二、第三颗各有六种结果，总情况数是 `6³ = 216`，并且每个有序三元组概率相同。

若点数和为 5，每颗至少为 1，只会出现两类数值构成：1、1、3，以及 1、2、2。第一类中，3 可以在三个位置之一；第二类中，1 也可以在三个位置之一，所以符合条件的有序结果一共六个：

```text
(1,1,3)、(1,3,1)、(3,1,1)
(1,2,2)、(2,1,2)、(2,2,1)

P(点数和为5) = 6/216 = 1/36
```

这里不能把两类数值构成直接当作两个等可能结果，因为每一类内部还包含不同位置的结果。分母既然使用有序三元组，分子也必须使用有序三元组计数。

## 三枚硬币至少出现一次正面

假设三次抛掷公平且相互独立，用 H 表示正面、T 表示反面，那么每次有两种结果，总情况数是 `2³ = 8`。事件 A 为至少出现一次正面，其补事件不是“至少一次反面”，而是“一次正面也没有”，也就是 TTT。

因此：

```text
P(Aᶜ) = P(TTT) = (1/2)³ = 1/8
P(A) = 1 − 1/8 = 7/8
```

也可以直接按恰好一次、两次、三次正面分类：分别有 `C(3,1) = 3`、`C(3,2) = 3`、`C(3,3) = 1` 种结果，总共七种。两种方法得到同一个答案，但补事件只需要处理一种结果，更容易避免遗漏。

日语题目中的「<span lang="ja" translate="no">少なくとも1回</span>」表示至少一次，「<span lang="ja" translate="no">ちょうど1回</span>」表示恰好一次。前者允许两次和三次也成立，后者只能保留 `C(3,1)` 那三种结果，两者不能混用。

## 十个球中至少抽到一个白球

沿用此前讨论的模型：袋中有七个白球、三个黑球，一次均匀抽出三个球，不放回，而且不区分抽取顺序。即使颜色相同，十个球仍可以分别编号，样本空间是从这十个不同球中选出的三球集合。

总情况数为 `C(10,3) = 120`。至少一个白球的补事件是三个全为黑球，黑球总共只有三个，因此符合补事件的集合只有 `C(3,3) = 1` 个：

```text
P(至少一个白球)
= 1 − P(三个全黑)
= 1 − C(3,3)/C(10,3)
= 119/120
```

这里不能把“零白、一白、二白、三白”当成四种等可能结果，因为每一种颜色构成所对应的三球集合数量不同。若改成每次抽出后放回，样本空间和概率规则都会变化，不能继续沿用这个分母。

## 互斥和独立要用不同关系判断

互斥描述两个事件不能同时发生，即 `A ∩ B = ∅`；独立（<span lang="ja" translate="no">独立</span> / independent）描述一个事件的发生不改变另一个事件的概率，可以用 `P(A ∩ B) = P(A)P(B)` 来判断。

如果两个互斥事件的概率都大于 0，它们的交集概率为 0，但概率乘积大于 0，因此不可能独立。一次公平骰子出现 1 与出现 2，就是这样的例子。

反过来，两次独立抛硬币中，“第一次正面”与“第二次正面”可以同时发生，并不互斥。不要把“两个事件互不影响”误读成“两个事件不能同时发生”。

还要注意，在一般的无限样本空间中，概率为 0 的事件不一定是空事件。例如从 `[0,1]` 中按均匀分布取一个数，恰好取到 1/2 的概率为 0，但 `{1/2}` 并不是空集。本文有限且各基本结果概率都为正的模型，可以更直观地把空事件与零概率联系起来，但这个判断不能无限推广。

## 用事件关系核对计算结果

1. 已知 `P(A) = 0.4`，A 的补事件概率是多少？
2. 已知 `P(A) = 0.4`、`P(B) = 0.5`、`P(A ∩ B) = 0.2`，并集与恰好一个发生的概率分别是多少？
3. 若 `A ⊆ B`、`P(A) = 0.3`、`P(B) = 0.8`，B 发生且 A 不发生的概率是多少？
4. 三次独立抛公平硬币，恰好一次正面的概率是多少？

第一题由补事件公式得到 0.6。第二题的并集为 `0.4 + 0.5 − 0.2 = 0.7`，恰好一个发生则要减去两次交集，得到 `0.4 + 0.5 − 0.4 = 0.5`。

第三题因为 A 包含在 B 中，所以差事件概率为 `0.8 − 0.3 = 0.5`。第四题选择三次中的哪一次出现正面，共有三种等可能结果，所以是 `C(3,1)/2³ = 3/8`。

复习时，先用集合写明事件，再检查互斥、包含或独立的条件，最后选择计数或概率公式。这样，计算中的每一步都能回到事件本身，也更容易发现重复计数、漏写前提和超过概率范围的问题。
