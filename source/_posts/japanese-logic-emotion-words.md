学了一段时间日语之后，常会遇到这样的情况：每个单词都认识，句子的语法也看得懂，却说不清作者到底想表达什么，或者自己说出的句子语法正确，听起来却怪怪的。原因往往在两个地方：一是日语怎样把句子连成论证，二是日语怎样表达感情。

这篇把这两部分分开研究。前半部分看接续词和文末表达怎样标出逻辑关系，后半部分看感情形容词的人称限制、「<span lang="ja" translate="no">がる</span>」、拟态词，以及「<span lang="ja" translate="no">やばい</span>」「<span lang="ja" translate="no">微妙</span>」这类意思随场合变化的词。

## 一、日语的论证结构

### 结论常常放在后面

日语的谓语在句末，否定、推测、判断都在最后才出现：

<div lang="ja" translate="no">

その計画は、予算の面でも人員の面でも、現時点では実行が難しいと言わざるを得ない**かもしれない**。

</div>

前面所有内容，直到最后的「<span lang="ja" translate="no">かもしれない</span>」才知道是一个推测，而不是断言。读长句时，先找句末的谓语和文末表达，再回头看修饰部分，理解会快很多。

段落层面也有类似倾向：日常文章、书信常见“背景 → 理由 → 结论”的顺序。不过商务文书和报告更推崇“结论先行”（<span lang="ja" translate="no">結論から言うと</span>），具体可以看[报告写作笔记](/posts/how-to-write-a-report/)。

### 接续词标出句与句的关系

接续词（<span lang="ja" translate="no">接続詞</span>）是理解日语逻辑最直接的线索。按功能分类：

| 功能 | 接续词 | 中文 |
| --- | --- | --- |
| 顺接（因果） | <span lang="ja" translate="no">だから・そのため・したがって・よって</span> | 所以、因此 |
| 逆接 | <span lang="ja" translate="no">しかし・だが・ところが・けれども</span> | 但是、然而 |
| 并列、添加 | <span lang="ja" translate="no">また・そして・さらに・しかも</span> | 另外、而且 |
| 对比、选择 | <span lang="ja" translate="no">一方・それに対して・または・あるいは</span> | 另一方面、或者 |
| 说明、换言 | <span lang="ja" translate="no">つまり・すなわち・要するに</span> | 也就是说、总之 |
| 补充理由 | <span lang="ja" translate="no">なぜなら・というのは</span> | 因为 |
| 举例 | <span lang="ja" translate="no">例えば</span> | 例如 |
| 转换话题 | <span lang="ja" translate="no">さて・ところで</span> | 那么、话说 |
| 条件归结 | <span lang="ja" translate="no">それなら・では</span> | 那样的话 |

几组需要区分的：

**「しかし」与「ところが」。** 两者都是逆接，但「<span lang="ja" translate="no">ところが</span>」表示结果与预期相反，带有意外感，后面接的是已经发生的事实：

- <span lang="ja" translate="no">天気予報では晴れだった。ところが、午後から大雨になった。</span>（○）
- <span lang="ja" translate="no">この方法は便利だ。しかし、コストが高い。</span>（○，只是对比两个性质）
- <span lang="ja" translate="no">この方法は便利だ。ところが、コストが高い。</span>（不自然：“成本高”不是意外发生的事）

**「だから」与「したがって」。** 意思相近，「<span lang="ja" translate="no">だから</span>」偏口语，可以带说话人的情绪（「<span lang="ja" translate="no">だから言ったでしょ！</span>」我早就说过了吧）；「<span lang="ja" translate="no">したがって</span>」「<span lang="ja" translate="no">よって</span>」用于书面和论证，「<span lang="ja" translate="no">よって</span>」常见于数学证明和法律文书。

**「つまり」与「要するに」。** 「<span lang="ja" translate="no">つまり</span>」是换一种说法说同一件事；「<span lang="ja" translate="no">要するに</span>」是概括要点，常常把前面的话压缩，有时带有“说了半天其实就是……”的不耐烦语气。

### 文末表达标出说话人的判断

日语在句末用不同的形式，表明这句话是事实、推论、说明还是应然。这部分是中国学习者最容易忽略的。

| 表达 | 核心含义 | 例句 |
| --- | --- | --- |
| 〜のだ／〜んです | 说明情况、给出背景 | <span lang="ja" translate="no">遅れてすみません。電車が止まっていたんです。</span> |
| 〜わけだ | 由前提推导出的合理结论 | <span lang="ja" translate="no">10 年も住んでいたのか。日本語が上手なわけだ。</span> |
| 〜はずだ | 根据依据推测，认为理应如此 | <span lang="ja" translate="no">午前中に発送したから、明日には届くはずだ。</span> |
| 〜べきだ | 义务、应该 | <span lang="ja" translate="no">約束は守るべきだ。</span> |
| 〜ものだ | 一般道理、感慨 | <span lang="ja" translate="no">時間が経つのは早いものだ。</span> |
| 〜ことだ | 忠告 | <span lang="ja" translate="no">上手になりたければ、毎日練習することだ。</span> |
| 〜に違いない | 强烈确信的推测 | <span lang="ja" translate="no">あの人が犯人に違いない。</span> |
| 〜かもしれない | 有可能 | <span lang="ja" translate="no">明日は雨かもしれない。</span> |
| 〜らしい | 根据传闻或迹象 | <span lang="ja" translate="no">あの店は来月閉店するらしい。</span> |
| 〜ようだ／みたいだ | 根据自己的观察 | <span lang="ja" translate="no">誰か来たようだ。</span> |
| 〜そうだ（样态） | 从外观判断 | <span lang="ja" translate="no">雨が降りそうだ。</span> |
| 〜そうだ（传闻） | 听说 | <span lang="ja" translate="no">雨が降るそうだ。</span> |

**「のだ」为什么这么常用。** 「<span lang="ja" translate="no">のだ</span>」把一句话变成对某个情况的说明。对比：

- <span lang="ja" translate="no">頭が痛いです。</span>（我头疼。只陈述事实）
- <span lang="ja" translate="no">頭が痛いんです。</span>（我头疼……暗示“所以想早退/所以今天不能去”）

问问题时也一样：「<span lang="ja" translate="no">どこへ行きますか。</span>」只是问去哪；「<span lang="ja" translate="no">どこへ行くんですか。</span>」表示看到对方要出门的样子，想知道背后的情况。不该用「<span lang="ja" translate="no">のだ</span>」的时候用了，会显得在追问或辩解；该用的时候没用，会显得生硬、没头没尾。

**「わけだ」与「はずだ」。** 两者都和推理有关，方向不同：

- 「<span lang="ja" translate="no">わけだ</span>」：已经知道结果，找到了原因后恍然大悟。「<span lang="ja" translate="no">寒いわけだ、窓が開いている。</span>」（怪不得冷，窗开着。）
- 「<span lang="ja" translate="no">はずだ</span>」：根据原因推测还未确认的结果。「<span lang="ja" translate="no">窓を閉めたから、もう寒くないはずだ。</span>」（关了窗，应该不冷了。）

「<span lang="ja" translate="no">はずがない</span>」是“不可能”，「<span lang="ja" translate="no">わけがない</span>」也是“不可能”，后者语气更强、更主观；「<span lang="ja" translate="no">わけではない</span>」则是“并不是说……”，用于部分否定，三者容易混淆。

### 用一段话练习追踪逻辑

<div lang="ja" translate="no">

在宅勤務は通勤時間がなくなるという利点がある。しかし、同僚と顔を合わせる機会が減るため、気軽な相談がしにくくなる。つまり、効率が上がる面と下がる面の両方があるわけだ。したがって、業務の性質に応じて出社日を決めるべきだろう。

</div>

| 句子 | 标记 | 作用 |
| --- | --- | --- |
| 第 1 句 | 无 | 提出优点 |
| 第 2 句 | しかし、〜ため | 逆接，提出缺点及其原因 |
| 第 3 句 | つまり、〜わけだ | 换言，总结前两句得出的推论 |
| 第 4 句 | したがって、〜べきだろう | 结论，提出建议，「だろう」缓和断定 |

只看画线的标记，就能还原出“优点—缺点—总结—建议”的结构。

## 二、日语的情感表达

### 感情形容词的人称限制

日语里，表达内心感受的形容词，在陈述句中原则上只能用于第一人称（说话人自己）：

| 形容词 | 意思 |
| --- | --- |
| <span lang="ja" translate="no">嬉しい・悲しい・寂しい</span> | 高兴、难过、寂寞 |
| <span lang="ja" translate="no">怖い・恥ずかしい・悔しい</span> | 害怕、害羞、不甘心 |
| <span lang="ja" translate="no">欲しい</span> | 想要 |
| <span lang="ja" translate="no">〜たい</span> | 想做 |
| <span lang="ja" translate="no">痛い・痒い・寒い</span> | 疼、痒、冷（身体感觉） |

- <span lang="ja" translate="no">私は嬉しい。</span>（○）
- <span lang="ja" translate="no">彼は嬉しい。</span>（×，别人内心的感受不能直接断言）

中文说“他很高兴”完全没问题，日语里却不能直接说。说别人的感情，需要加上表示“从外部观察”或“传闻、推测”的形式：

| 形式 | 例句 | 含义 |
| --- | --- | --- |
| 〜がる | <span lang="ja" translate="no">彼は嬉しがっている。</span> | 他表现出高兴的样子 |
| 〜そうだ | <span lang="ja" translate="no">彼は嬉しそうだ。</span> | 他看起来很高兴 |
| 〜ようだ／みたいだ | <span lang="ja" translate="no">彼は嬉しいようだ。</span> | 他好像很高兴 |
| 〜らしい | <span lang="ja" translate="no">彼は嬉しいらしい。</span> | 据说他很高兴 |
| 〜と言っている | <span lang="ja" translate="no">彼は嬉しいと言っている。</span> | 他说他很高兴 |
| 〜のだ | <span lang="ja" translate="no">彼は嬉しいのだ。</span> | （叙述者解释）他是高兴啊 |

疑问句可以问第二人称：「<span lang="ja" translate="no">嬉しい？</span>」（你高兴吗？）因为是在询问对方，而不是替对方断言。小说里全知视角的叙述者也可以直接写人物的感受，这是文学的约定。

同样，「<span lang="ja" translate="no">〜たい</span>」用于他人时变成「<span lang="ja" translate="no">〜たがる</span>」：

- <span lang="ja" translate="no">子どもはいつも外で遊びたがる。</span>（孩子总想到外面玩。）
- <span lang="ja" translate="no">弟が新しいゲームを欲しがっている。</span>（弟弟想要新游戏。）

注意「<span lang="ja" translate="no">欲しがる</span>」的对象用「<span lang="ja" translate="no">を</span>」，而「<span lang="ja" translate="no">欲しい</span>」的对象用「<span lang="ja" translate="no">が</span>」。「<span lang="ja" translate="no">がる</span>」把形容词变成了他动词。

### 「〜がる」的语感

「<span lang="ja" translate="no">がる</span>」描述的是外在表现，有时带有“明显表露出来”“毫不掩饰”的语气，用在上级或长辈身上会显得失礼：

- <span lang="ja" translate="no">部長は寂しがっていました。</span>（有点不礼貌，好像在评论部长的样子）
- <span lang="ja" translate="no">部長は寂しそうでした。</span>（更稳妥）

「<span lang="ja" translate="no">強がる</span>」（逞强）、「<span lang="ja" translate="no">面白がる</span>」（觉得有趣而起哄）、「<span lang="ja" translate="no">怖がる</span>」（害怕）是常用的复合词。

### 同一种感情的不同强度

| 感情 | 弱 → 强 |
| --- | --- |
| 高兴 | <span lang="ja" translate="no">よかった → 嬉しい → 最高 → 感無量（かんむりょう）</span> |
| 生气 | <span lang="ja" translate="no">むっとする → イライラする → 腹が立つ → 頭にくる → キレる</span> |
| 难过 | <span lang="ja" translate="no">しょんぼり → 落ち込む → 悲しい → 胸が張り裂ける</span> |
| 害怕 | <span lang="ja" translate="no">不安 → 怖い → ぞっとする → 恐ろしい</span> |
| 羞耻 | <span lang="ja" translate="no">照れる → 恥ずかしい → 穴があったら入りたい</span> |

「<span lang="ja" translate="no">照れる</span>」是被夸奖时的害羞，带着一点开心；「<span lang="ja" translate="no">恥ずかしい</span>」可以是害羞，也可以是丢脸；「<span lang="ja" translate="no">穴があったら入りたい</span>」是“恨不得找个地缝钻进去”。

「<span lang="ja" translate="no">悔しい</span>」没有完全对应的中文词，是输了、被比下去时“不甘心、窝火”的感觉，和「<span lang="ja" translate="no">残念</span>」（遗憾）不同。比赛输了会说「<span lang="ja" translate="no">悔しい！</span>」，活动取消了说「<span lang="ja" translate="no">残念</span>」。

### 用身体部位表达感情

日语有大量借身体表达心情的惯用句：

| 惯用句 | 意思 |
| --- | --- |
| <span lang="ja" translate="no">胸がいっぱいになる</span> | 心中充满感动 |
| <span lang="ja" translate="no">胸が痛む</span> | 心痛、难过 |
| <span lang="ja" translate="no">腹が立つ</span> | 生气 |
| <span lang="ja" translate="no">頭にくる</span> | 火冒三丈 |
| <span lang="ja" translate="no">気が重い</span> | 心情沉重、不想做 |
| <span lang="ja" translate="no">気が楽になる</span> | 心情轻松 |
| <span lang="ja" translate="no">肩の荷が下りる</span> | 卸下重担、松一口气 |
| <span lang="ja" translate="no">顔から火が出る</span> | 羞得脸发烫 |
| <span lang="ja" translate="no">手に汗を握る</span> | 捏一把汗 |

### 拟态词让感情有了声音

拟声拟态词（<span lang="ja" translate="no">オノマトペ</span>）在日语里用得极多，很多感情状态用它们说比用形容词更自然：

| 拟态词 | 感情 | 例句 |
| --- | --- | --- |
| <span lang="ja" translate="no">ドキドキ</span> | 心跳加速（紧张或心动） | <span lang="ja" translate="no">面接の前でドキドキする。</span> |
| <span lang="ja" translate="no">ワクワク</span> | 期待、兴奋 | <span lang="ja" translate="no">旅行が楽しみでワクワクする。</span> |
| <span lang="ja" translate="no">イライラ</span> | 烦躁 | <span lang="ja" translate="no">電車が来なくてイライラした。</span> |
| <span lang="ja" translate="no">ハラハラ</span> | 为别人担心、提心吊胆 | <span lang="ja" translate="no">子どもの運転にハラハラした。</span> |
| <span lang="ja" translate="no">モヤモヤ</span> | 心里不痛快、说不清的郁闷 | <span lang="ja" translate="no">言いたいことが言えずモヤモヤする。</span> |
| <span lang="ja" translate="no">ホッと</span> | 松了口气 | <span lang="ja" translate="no">無事に着いてホッとした。</span> |
| <span lang="ja" translate="no">ムカムカ</span> | 恶心，或怒气上涌 | <span lang="ja" translate="no">あの態度を思い出すとムカムカする。</span> |
| <span lang="ja" translate="no">ウキウキ</span> | 雀跃、心情轻快 | <span lang="ja" translate="no">週末が近くてウキウキしている。</span> |
| <span lang="ja" translate="no">しょんぼり</span> | 垂头丧气 | <span lang="ja" translate="no">叱られてしょんぼりしている。</span> |

「<span lang="ja" translate="no">ドキドキ</span>」和「<span lang="ja" translate="no">ワクワク</span>」的区别：前者是心跳的生理感受，可以来自紧张也可以来自心动；后者只用于对将来的好事充满期待。「<span lang="ja" translate="no">ハラハラ</span>」是担心别人，「<span lang="ja" translate="no">ドキドキ</span>」是自己紧张。

### 意思由语境决定的词

**「やばい」** 原本是“危险、不妙”，现在年轻人口语里也表示“太棒了、厉害”。

- <span lang="ja" translate="no">寝坊した、やばい！</span>（睡过头了，糟了！）
- <span lang="ja" translate="no">このケーキ、やばい！</span>（这个蛋糕太好吃了！）

正式场合避免使用。

**「微妙（びみょう）」** 字面是“微妙”，口语中常常是委婉的否定：“不太好”“说不上好”。

- <span lang="ja" translate="no">あの映画どうだった？——うーん、微妙。</span>（那部电影怎么样？——嗯……一般吧／不怎么样。）

**「大丈夫」** 既可以是“没问题”，也可以是委婉的拒绝：

- <span lang="ja" translate="no">袋はご利用ですか？——大丈夫です。</span>（需要袋子吗？——不用了。）

**「結構です」** 同样两用：「<span lang="ja" translate="no">それで結構です</span>」是“那样就可以”，单独说「<span lang="ja" translate="no">結構です</span>」通常是“不用了”。

**「すみません」** 可以是道歉、感谢（麻烦你了）、叫人（不好意思打扰一下）。日语倾向于在感谢时也表达“给你添了麻烦”的歉意。

### 不直接说出来的感情

日语里，很多负面情绪不会直接说，而是用省略或委婉的方式让对方意会：

| 说法 | 字面 | 实际意思 |
| --- | --- | --- |
| <span lang="ja" translate="no">ちょっと…</span> | 有点…… | 不行、不方便 |
| <span lang="ja" translate="no">考えておきます</span> | 我考虑一下 | 多半是拒绝 |
| <span lang="ja" translate="no">前向きに検討します</span> | 积极考虑 | 有可能，但没承诺 |
| <span lang="ja" translate="no">それはちょっと難しいですね</span> | 那有点难 | 做不到 |
| <span lang="ja" translate="no">お気持ちだけいただきます</span> | 心意我领了 | 礼物/好意我不收 |

日语里，听者读出没说出口的意思，叫「<span lang="ja" translate="no">察する</span>」，善于察言观色叫「<span lang="ja" translate="no">空気を読む</span>」。对学习者来说，需要知道这些说法通常不是字面意思。

## 三、两部分的共同点

逻辑表达和情感表达看起来是两个话题，背后其实是同一个特点：日语很在意说话人和信息之间的距离。

- 自己确定的事实，用断定；推测的，用「<span lang="ja" translate="no">はずだ・だろう・かもしれない</span>」分级。
- 自己的感受可以直接说；别人的感受只能通过观察、传闻或推测间接说。
- 对听话人，需要说明背景时用「<span lang="ja" translate="no">のだ</span>」，需要缓和时用省略和委婉。

学习时，与其一个个背接续词和形容词，不如每遇到一句话都问一下：说话人对这件事有多确定？这件事是谁的经验？这样，文末表达和感情词的选择会自然很多。

## 练习

1. 选择合适的词填空：<span lang="ja" translate="no">一生懸命勉強した。（　　）、試験に落ちてしまった。</span>（しかし／ところが）
2. 改正：<span lang="ja" translate="no">友達は新しいスマホが欲しい。</span>
3. 说明区别：<span lang="ja" translate="no">「彼は来るはずだ」と「彼が来たわけだ」。</span>
4. 用拟态词表达：等待考试成绩公布时的紧张心情。

**解答**

1. 两者都可以，但「<span lang="ja" translate="no">ところが</span>」更能表达“与预期相反”的意外感。
2. <span lang="ja" translate="no">友達は新しいスマホを欲しがっている。</span>／<span lang="ja" translate="no">欲しいらしい。</span>／<span lang="ja" translate="no">欲しいと言っている。</span>
3. 前者是根据依据推测还没发生的事“他应该会来”；后者是已经知道某个结果，理解了原因“（原来如此，）他来了啊”。
4. <span lang="ja" translate="no">結果発表を待ちながらドキドキしている。</span>
