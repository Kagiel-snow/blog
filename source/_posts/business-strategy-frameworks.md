经营战略（<span lang="ja" translate="no">経営戦略</span>）回答的问题是：企业在有限的资源下，应该在哪里竞争、怎样竞争。它是 IT 护照等考试中“战略系”的重要部分，也是理解信息系统为什么要这样建设的前提：系统战略要服从经营战略。

框架很多，容易背成一堆缩写。这篇按“确定目标 → 分析环境 → 选择战略 → 执行与评价”的顺序整理，每个框架都写清它回答什么问题，用一个虚构的例子贯穿。

<!-- more -->

## 贯穿全文的例子

一家虚构的公司「さくら書店」：在地方城市经营三家实体书店，最近销售额连年下降。全文会用各个框架分析它。

## 一、从理念到目标

| 概念 | 日语 | 含义 |
| --- | --- | --- |
| 经营理念 | <span lang="ja" translate="no">経営理念</span> | 企业存在的意义和价值观，长期不变 |
| 愿景 | <span lang="ja" translate="no">ビジョン</span> | 将来想成为的样子 |
| 使命 | <span lang="ja" translate="no">ミッション</span> | 企业对社会承担的任务 |
| 经营目标 | <span lang="ja" translate="no">経営目標</span> | 具体、可衡量的目标（销售额、市场份额等） |
| 经营战略 | <span lang="ja" translate="no">経営戦略</span> | 实现目标的方针和资源分配 |

战略有三个层级：

| 层级 | 日语 | 回答的问题 | 例子 |
| --- | --- | --- | --- |
| 全公司战略 | <span lang="ja" translate="no">企業戦略・全社戦略</span> | 做哪些事业？资源怎样分配？ | 是否进入电子书市场 |
| 事业战略 | <span lang="ja" translate="no">事業戦略・競争戦略</span> | 在某个事业中怎样赢过竞争对手？ | 书店怎样与网购竞争 |
| 职能战略 | <span lang="ja" translate="no">機能別戦略</span> | 营销、人事、IT 等各职能怎样支持？ | 引入会员积分系统 |

## 二、分析环境

### 3C 分析

从三个角度看市场：

| C | 日语 | 看什么 |
| --- | --- | --- |
| Customer | <span lang="ja" translate="no">市場・顧客</span> | 市场规模、需求变化 |
| Competitor | <span lang="ja" translate="no">競合</span> | 竞争对手的优势和策略 |
| Company | <span lang="ja" translate="no">自社</span> | 自己的资源和强项 |

さくら書店：顾客中年轻人转向网购和电子书，但亲子读者仍重视实际翻看；竞争对手是大型网购平台和郊外的大型书店；自己的强项是店员熟悉本地读者、店铺位于车站附近。

### SWOT 分析

把内部和外部、正面和负面交叉：

| | 正面 | 负面 |
| --- | --- | --- |
| **内部** | S 强项（<span lang="ja" translate="no">強み</span>） | W 弱项（<span lang="ja" translate="no">弱み</span>） |
| **外部** | O 机会（<span lang="ja" translate="no">機会</span>） | T 威胁（<span lang="ja" translate="no">脅威</span>） |

内部是公司能控制的（人才、技术、品牌、资金），外部是公司控制不了的（市场、法规、竞争、技术趋势）。考试常问某一项应该归入哪一格，判断依据就是“能否由自己控制”。

さくら書店的 SWOT：

| | |
| --- | --- |
| S | 车站附近的店址；熟悉本地读者的店员 |
| W | 没有网店；库存管理靠人工 |
| O | 地方政府推动亲子阅读；“到店体验”消费受关注 |
| T | 网购和电子书普及；人口减少 |

**交叉 SWOT** 把四格组合成战略选项：

| 组合 | 方向 | 例子 |
| --- | --- | --- |
| S × O | 用强项抓住机会 | 店员举办亲子读书会，与地方政府合作 |
| S × T | 用强项应对威胁 | 发挥选书能力，做网购做不到的推荐 |
| W × O | 克服弱项抓住机会 | 建立网上预约、到店取书 |
| W × T | 避免最坏情况 | 关闭亏损店铺，集中资源 |

### PEST 分析

分析宏观环境：政治（<span lang="ja" translate="no">Politics</span>）、经济（<span lang="ja" translate="no">Economy</span>）、社会（<span lang="ja" translate="no">Society</span>）、技术（<span lang="ja" translate="no">Technology</span>）。它是 SWOT 中“外部”的来源之一。

### 五力分析

波特的五力分析（<span lang="ja" translate="no">ファイブフォース分析</span>）从五个方面看一个行业的竞争有多激烈、利润空间有多大：

| 力量 | 日语 | 书店行业的情况 |
| --- | --- | --- |
| 行业内竞争 | <span lang="ja" translate="no">業界内の競争</span> | 大型书店、连锁店竞争 |
| 新进入者的威胁 | <span lang="ja" translate="no">新規参入の脅威</span> | 网购平台进入门槛低 |
| 替代品的威胁 | <span lang="ja" translate="no">代替品の脅威</span> | 电子书、短视频、免费网络内容 |
| 买方的议价能力 | <span lang="ja" translate="no">買い手の交渉力</span> | 顾客可以轻松比价 |
| 卖方的议价能力 | <span lang="ja" translate="no">売り手の交渉力</span> | 出版社和批发商 |

五股力量越强，行业的平均利润越低。

## 三、全公司战略

### PPM

产品组合管理（<span lang="ja" translate="no">プロダクトポートフォリオマネジメント</span> / PPM）用市场增长率和相对市场份额两个轴，把事业分成四类，决定资金怎样分配：

| | 市场份额高 | 市场份额低 |
| --- | --- | --- |
| **市场增长率高** | 明星（<span lang="ja" translate="no">花形</span>） | 问题儿童（<span lang="ja" translate="no">問題児</span>） |
| **市场增长率低** | 现金牛（<span lang="ja" translate="no">金のなる木</span>） | 瘦狗（<span lang="ja" translate="no">負け犬</span>） |

| 类型 | 资金 | 方针 |
| --- | --- | --- |
| 明星 | 收入多，投入也多 | 维持份额，市场成熟后成为现金牛 |
| 现金牛 | 收入多，投入少 | 赚取资金，投给明星和问题儿童 |
| 问题儿童 | 收入少，投入多 | 选择性投资，培养成明星或退出 |
| 瘦狗 | 收入少 | 考虑撤退 |

考试中常给出“市场增长率高、份额低”之类的描述，问属于哪一类。记住纵轴是增长率（市场的吸引力），横轴是份额（自己的竞争力）。

### 安索夫成长矩阵

安索夫的成长矩阵（<span lang="ja" translate="no">アンゾフの成長マトリクス</span>）按产品和市场是否是新的，分出四种成长方向：

| | 现有产品 | 新产品 |
| --- | --- | --- |
| **现有市场** | 市场渗透（<span lang="ja" translate="no">市場浸透</span>） | 新产品开发（<span lang="ja" translate="no">新製品開発</span>） |
| **新市场** | 新市场开拓（<span lang="ja" translate="no">新市場開拓</span>） | 多元化（<span lang="ja" translate="no">多角化</span>） |

さくら書店：给现有顾客发会员卡提高到店次数是市场渗透；在店里开咖啡区是新产品开发；在邻市开店是新市场开拓；开办面向老人的社区学习教室是多元化。

多元化风险最大，因为产品和市场都是陌生的。

### 其他全公司层面的手段

| 手段 | 日语 | 含义 |
| --- | --- | --- |
| 并购 | <span lang="ja" translate="no">M&A</span> | 收购或合并其他企业 |
| 业务合作 | <span lang="ja" translate="no">アライアンス</span> | 不合并，在特定领域合作 |
| 外包 | <span lang="ja" translate="no">アウトソーシング</span> | 把非核心业务交给外部 |
| 垂直整合 | <span lang="ja" translate="no">垂直統合</span> | 进入上游或下游（如书店自己做出版） |
| 水平整合 | <span lang="ja" translate="no">水平統合</span> | 与同行业企业合并 |

## 四、事业战略：怎样竞争

### 波特的三种基本战略

| 战略 | 日语 | 含义 |
| --- | --- | --- |
| 成本领先 | <span lang="ja" translate="no">コストリーダーシップ戦略</span> | 以行业最低成本竞争 |
| 差异化 | <span lang="ja" translate="no">差別化戦略</span> | 提供对手没有的价值，收取更高价格 |
| 集中 | <span lang="ja" translate="no">集中戦略</span> | 专注特定市场（细分市场），在其中做成本或差异化 |

さくら書店不可能在价格和品种上赢过大型网购平台，现实的选择是集中加差异化：专注亲子读者和本地读者，用选书、活动和店员的推荐建立差异。

### 竞争地位战略

科特勒按市场地位把企业分成四类：

| 地位 | 日语 | 典型战略 |
| --- | --- | --- |
| 领导者 | <span lang="ja" translate="no">リーダー</span> | 扩大整个市场，全方位覆盖 |
| 挑战者 | <span lang="ja" translate="no">チャレンジャー</span> | 与领导者差异化，争夺份额 |
| 追随者 | <span lang="ja" translate="no">フォロワー</span> | 模仿领导者，降低成本 |
| 补缺者 | <span lang="ja" translate="no">ニッチャー</span> | 专注领导者不重视的小市场 |

### 价值链

波特的价值链（<span lang="ja" translate="no">バリューチェーン</span>）把企业活动分成主要活动和支援活动，分析哪个环节创造了价值：

- 主要活动：采购物流、制造、出货物流、销售与营销、服务
- 支援活动：基础设施（经营管理）、人事、技术开发、采购

找出自己在哪个环节有优势，就知道应该在哪里投资，哪些可以外包。

### VRIO 分析与核心竞争力

VRIO 用四个问题判断一项经营资源能否带来持续的竞争优势：

| 问题 | 日语 | 含义 |
| --- | --- | --- |
| Value | <span lang="ja" translate="no">経済価値</span> | 能否带来价值？ |
| Rarity | <span lang="ja" translate="no">希少性</span> | 是否稀有？ |
| Imitability | <span lang="ja" translate="no">模倣困難性</span> | 是否难以模仿？ |
| Organization | <span lang="ja" translate="no">組織</span> | 组织能否发挥它？ |

四项都满足，才是持续的竞争优势。

核心竞争力（<span lang="ja" translate="no">コアコンピタンス</span>）是对手难以模仿、能在多个事业中发挥作用的核心能力。さくら書店的“熟悉本地读者的选书能力”可能是它的核心竞争力，因为网购平台的推荐算法难以复制地方社区的人际关系。

## 五、市场营销

### STP

| 步骤 | 日语 | 含义 |
| --- | --- | --- |
| Segmentation | <span lang="ja" translate="no">セグメンテーション</span> | 按年龄、地域、需求等把市场细分 |
| Targeting | <span lang="ja" translate="no">ターゲティング</span> | 选择要服务的细分市场 |
| Positioning | <span lang="ja" translate="no">ポジショニング</span> | 确定在顾客心中的定位 |

### 4P 与 4C

营销组合（<span lang="ja" translate="no">マーケティングミックス</span>）从企业角度看是 4P，从顾客角度看是 4C：

| 4P（企业视角） | 4C（顾客视角） |
| --- | --- |
| Product 产品 | Customer Value 顾客价值 |
| Price 价格 | Cost 顾客负担的成本 |
| Place 渠道 | Convenience 便利性 |
| Promotion 促销 | Communication 沟通 |

### 产品生命周期

| 阶段 | 日语 | 特点 | 战略 |
| --- | --- | --- | --- |
| 导入期 | <span lang="ja" translate="no">導入期</span> | 销量少，认知度低 | 提高认知 |
| 成长期 | <span lang="ja" translate="no">成長期</span> | 销量急增，竞争者进入 | 扩大份额 |
| 成熟期 | <span lang="ja" translate="no">成熟期</span> | 销量见顶，竞争激烈 | 差异化，维持份额 |
| 衰退期 | <span lang="ja" translate="no">衰退期</span> | 销量下降 | 削减成本或撤退 |

### 其他常考用语

| 用语 | 含义 |
| --- | --- |
| <span lang="ja" translate="no">CRM</span> | 顾客关系管理，长期维护与顾客的关系 |
| <span lang="ja" translate="no">ワントゥワンマーケティング</span> | 针对个别顾客的营销 |
| <span lang="ja" translate="no">オムニチャネル</span> | 打通店铺和网络等所有渠道 |

| <span lang="ja" translate="no">コモディティ化</span> | 产品同质化，只能比价格 |

## 六、执行与评价

### 平衡计分卡

平衡计分卡（<span lang="ja" translate="no">バランススコアカード</span> / BSC）不只看财务数字，从四个视角设定目标和指标：

| 视角 | 日语 | さくら書店的指标例 |
| --- | --- | --- |
| 财务 | <span lang="ja" translate="no">財務の視点</span> | 营业利润率 |
| 顾客 | <span lang="ja" translate="no">顧客の視点</span> | 会员复购率、读书会参加人数 |
| 业务流程 | <span lang="ja" translate="no">業務プロセスの視点</span> | 预约书的到货天数 |
| 学习与成长 | <span lang="ja" translate="no">学習と成長の視点</span> | 店员的选书培训时间 |

四个视角有因果关系：员工成长 → 流程改善 → 顾客满意 → 财务成果。

### KGI、KPI 与 CSF

| 用语 | 含义 | 例 |
| --- | --- | --- |
| KGI（<span lang="ja" translate="no">重要目標達成指標</span>） | 最终目标 | 年销售额恢复到 3 年前的水平 |
| CSF（<span lang="ja" translate="no">重要成功要因</span>） | 达成目标的关键因素 | 增加亲子读者的到店次数 |
| KPI（<span lang="ja" translate="no">重要業績評価指標</span>） | 衡量过程的指标 | 每月读书会参加人数 |

先定 KGI，再找 CSF，最后为 CSF 设定可以衡量的 KPI。

## 七、与信息系统的关系

系统战略要服从经营战略。さくら書店如果选择“集中 + 差异化”，信息系统的投资方向就应该是会员管理（CRM）、网上预约与到店取书（オムニチャネル）、读书会报名系统，而不是追求和网购平台比拼的大规模物流系统。

这也是 IT 护照考试把经营战略放在“战略系”的原因：IT 的价值，最终要用经营目标来衡量。具体的考试题型可以参考[IT 护照令和 6 年度解析](/posts/it-passport-r6-explained/)。

## 练习

1. “竞争对手推出了低价商品”在 SWOT 中属于哪一项？
2. 市场增长率低、自己的市场份额高的事业，在 PPM 中属于哪一类？应采取什么方针？
3. 一家只卖面包的店开始在同一家店卖咖啡豆，属于安索夫矩阵的哪一种？
4. 说明“差异化战略”和“集中战略”的区别。

**解答**

1. 威胁（T）。竞争对手的行动是外部因素，对自己不利。
2. 现金牛。投入少、收入多，用它赚到的资金支持明星和问题儿童。
3. 对现有顾客（现有市场）推出新产品，是新产品开发。
4. 差异化是在广泛的市场上以独特价值竞争；集中是把范围缩小到特定的细分市场，在那里实行成本领先或差异化。两者的区别在于目标市场的范围。
