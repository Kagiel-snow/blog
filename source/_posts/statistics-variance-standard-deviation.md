均值描述一组数值的中心，方差与标准差描述数值围绕中心的分散程度。即使两组数据的均值相同，它们的波动也可能很不相同；即使两个样本的均值不同，也不能仅凭这个差值断定对应总体存在统计学上的显著差异。

本文从偏差平方和出发，推导方差的两种常见分母，完整计算 16 个零件以及 A、B 两组零件的统计量，并讨论单位、自由度、数值算法和 Excel 实现。中心位置的选择可结合[均值与中位数笔记](/posts/statistics-mean-median/)阅读；抽样模型中的概率概念可参照[概率基本性质笔记](/posts/probability-basic-properties/)。

## 用偏差描述数据相对于均值的位置

设一组数值为 x₁、x₂、……、xₙ，n 是有效观测值的个数。算术平均数，简称均值（<span lang="ja" translate="no">平均値・へいきんち</span> / arithmetic mean），定义为：

```text
x̄ = (x₁ + x₂ + … + xₙ) / n
```

第 i 个观测值与均值之差 `xᵢ − x̄` 称为偏差（<span lang="ja" translate="no">偏差・へんさ</span> / deviation）。偏差为正表示该值高于均值，偏差为负表示低于均值。所有偏差相加必然等于零：

```text
Σ(xᵢ − x̄)
= Σxᵢ − nx̄
= Σxᵢ − Σxᵢ
= 0
```

因此，直接把带符号的偏差平均起来，无法测量离散程度。无论数据集中还是分散，这个平均都等于零。例如 `{4,5,6}` 与 `{0,5,10}` 的均值都是 5，偏差总和都是 0，但后者显然更分散。

偏差平方和（<span lang="ja" translate="no">偏差平方和・へんさへいほうわ</span> / sum of squared deviations）记为 SS：

```text
SS = Σ(xᵢ − x̄)²
```

平方使正负偏差不再相互抵消，同时使较大的偏差得到较大的权重。距离均值 1 个单位的观测贡献 1，距离 3 个单位的观测贡献 9。SS 总是非负，并且只有所有数值相同时才等于零。这也意味着方差和标准差容易受到极端观测的影响。[NIST 关于离散程度的说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm)将这种平方加权性质与其他离散指标作了比较。

SS 还会受到观测个数影响。如果把整组数据重复记录一次，均值不变，SS 却变为原来的两倍。因此，要比较不同样本量的数据，通常需要进一步归一化，而不是只比较 SS。

## 偏差平方和的计算式来自代数展开

定义式便于理解，但逐项减均值可能带来许多小数。展开平方后，可以得到手算常用的恒等式：

```text
SS = Σ(xᵢ − x̄)²
   = Σxᵢ² − 2x̄Σxᵢ + nx̄²

因为 Σxᵢ = nx̄，所以：

SS = Σxᵢ² − 2nx̄² + nx̄²
   = Σxᵢ² − nx̄²
   = Σxᵢ² − (Σxᵢ)²/n
```

这三个量必须区分：`Σxᵢ²` 是先将每个数平方再相加，`(Σxᵢ)²` 是先相加再平方，SS 则是相对于均值的偏差平方和。例如数据 `{2,4,6}` 有：

```text
Σxᵢ  = 12
Σxᵢ² = 4 + 16 + 36 = 56
(Σxᵢ)² = 144

SS = 56 − 144/3 = 8
```

按定义式核算同样得到 `(-2)² + 0² + 2² = 8`。后面的案例将保留总和与平方和，便于独立复核。

## 分母 n 与 n−1 回答不同的问题

如果目的是描述当前这 n 个数本身，可以使用平均平方偏差：

```text
vₙ = SS/n
```

如果这 n 个数就是研究范围内全部个体，vₙ 就是这个有限总体的方差。更一般地，即使数据来自样本，SS/n 仍然可以作为该数据集的描述性统计量；需要说明采用了哪一种定义。

当把数据看作来自更大总体的随机样本，并用它估计总体方差时，常使用样本方差：

```text
s² = SS/(n − 1)，要求 n ≥ 2
s  = √s²
```

s² 称为样本方差（sample variance），s 称为样本标准差（sample standard deviation）。日语中的“方差”通常写作「<span lang="ja" translate="no">分散・ぶんさん</span>」，不偏方差写作「<span lang="ja" translate="no">不偏分散・ふへんぶんさん</span>」，标准差写作「<span lang="ja" translate="no">標準偏差・ひょうじゅんへんさ</span>」。部分教材将 SS/n 称为样本方差，将 SS/(n−1) 单独称为不偏方差，因此阅读时应以公式为准。

对同一数据集，两种方差有明确关系：

```text
s² = n/(n−1) × vₙ
```

只要 SS 大于 0，除以 n−1 的结果就稍大。随着 n 增加，比例 n/(n−1) 趋近于 1。但选择分母仍应由统计目标决定，不能因为两个数接近就混用。

只有一个数时，描述性方差 SS/n 等于 0，表示这一个观测没有内部离散；它不能提供总体方差的有效估计。此时 SS/(n−1) 的分母为零，样本方差没有定义。

## 自由度与无偏性的含义

自由度（<span lang="ja" translate="no">自由度・じゆうど</span> / degrees of freedom）描述在约束下可以独立变化的数量。n 个偏差满足一个线性约束：

```text
(x₁−x̄) + … + (xₙ−x̄) = 0
```

给定前 n−1 个偏差，最后一个就由它们的和确定，所以偏差向量只有 n−1 个自由度。这解释了“用数据估计一个均值会消耗一个自由度”。不过，自由度的直观解释之外，还需要概率推导才能证明除以 n−1 的无偏性。

设 X₁、……、Xₙ 是独立同分布的随机变量，具有共同均值 μ 和有限方差 σ²。随机样本均值记为 X̄。在这些条件下：

```text
E[X̄] = μ
Var(X̄) = σ²/n

Σ(Xᵢ − X̄)²
= Σ(Xᵢ − μ)² − n(X̄ − μ)²
```

对最后一个恒等式取期望，因为 `E[(Xᵢ−μ)²] = σ²`，且 `E[(X̄−μ)²] = Var(X̄)`，得到：

```text
E[SS] = nσ² − n×σ²/n
      = (n − 1)σ²

E[SS/(n − 1)] = σ²
E[SS/n]       = (n − 1)σ²/n
```

这就是贝塞尔校正（Bessel's correction）的依据。估计得到的样本均值会适应当前数据，使围绕它的平方距离比围绕真实总体均值的平方距离平均更小。分母 n−1 补偿这一平均意义上的低估。

“无偏”意味着在同样的抽样机制下反复抽样，估计量的期望等于目标参数。它不意味着每一次计算结果都恰好等于总体方差。上述结论不要求正态分布，但要求独立同分布与有限方差；重复测量、聚类数据或有依赖的时间序列不能直接套用这段证明。

如果总体均值 μ 已知，则可以使用 `Σ(Xᵢ−μ)²/n` 无偏估计 σ²，因为中心没有通过当前样本估计。另一个常见误区是认为“方差无偏，所以标准差也无偏”：平方根是非线性变换，一般 `E[√s²] ≠ √E[s²]`，因而 s 通常不是 σ 的无偏估计量。

## 完整计算 16 个零件的离散程度

16 个零件的重量观测值为：

```text
64, 59, 62, 59, 61, 63, 61, 61,
61, 59, 62, 63, 59, 60, 60, 64
```

以下保留观测数值。若重量单位为 g，则均值与标准差单位为 g，方差与 SS 单位为 g²；若使用其他单位，按相同规则替换。

先统计各数值的频数，以同时检查数据个数、总和与平方和：

| 数值 x | 频数 f | f×x | f×x² |
| ---: | ---: | ---: | ---: |
| 59 | 4 | 236 | 13924 |
| 60 | 2 | 120 | 7200 |
| 61 | 4 | 244 | 14884 |
| 62 | 2 | 124 | 7688 |
| 63 | 2 | 126 | 7938 |
| 64 | 2 | 128 | 8192 |
| 合计 | 16 | 978 | 59826 |

因此：

```text
n = 16
Σxᵢ = 978
Σxᵢ² = 59826
x̄ = 978/16 = 61.125

SS = 59826 − 978²/16
   = 59826 − 956484/16
   = 59826 − 59780.25
   = 45.75
```

用定义式复核时，可以按照频数加权：

```text
SS = 4×(59−61.125)² + 2×(60−61.125)²
   + 4×(61−61.125)² + 2×(62−61.125)²
   + 2×(63−61.125)² + 2×(64−61.125)²

   = 18.0625 + 2.53125 + 0.0625
   + 1.53125 + 7.03125 + 16.53125
   = 45.75
```

采用 n−1 的样本方差定义，结果为：

```text
s² = 45.75/(16−1) = 45.75/15 = 3.05
s  = √3.05 ≈ 1.7464249
```

标准差保留四位小数为 1.7464，保留两位小数为 1.75。应在最后一步舍入，不应先把均值 61.125 改成 61，再用舍入后的中心计算 SS。

如果描述这 16 个数本身，采用分母 n，则得到另一组有明确含义的数值：

```text
v₁₆ = 45.75/16 = 2.859375
√v₁₆ ≈ 1.6909687
```

| 统计量 | 数值 |
| --- | ---: |
| 均值 x̄ | 61.125 |
| 偏差平方和 SS | 45.75 |
| 样本方差 s²，分母 15 | 3.05 |
| 样本标准差 s | 约 1.7464 |
| 描述性方差 v₁₆，分母 16 | 2.859375 |

## 样本均值不同与总体均值不同需要分开

对已观测的这 20 个数，可以直接给出确定的描述性结论：B 组均值比 A 组高 `9.7 − 8.1 = 1.6`。如果重量单位为 g，这个差值就是 1.6 g。B 组样本方差也较大，但这只是对当前两个样本的计算结果。

总体均值通常记为 μA 和 μB。要讨论 `μA = μB` 是否与数据相容，必须说明样本如何获得、组内观测是否独立、两组是否独立、测量是否可比，以及采用什么概率模型。小样本检验还需要考察分布假设与极端值；若数据来自配对实验或同一批零件的重复测量，应采用相应的分析方式。

因此，仅凭两个均值不相等，不能写成“两个总体存在显著差异”。总体即使具有相同均值，随机样本的均值也通常不会完全相同；反过来，某次样本均值接近也不能证明总体均值相同。统计推断需要把观察到的差值与抽样波动联系起来，并预先明确检验目标与判断标准。

标准差也不能直接当作均值估计的标准误。独立同分布且方差有限时，样本均值的标准差为 `σ/√n`，常用估计为 `s/√n`。标准差 s 描述单个观测的离散程度，标准误估计 s/√n 描述反复抽样时均值的波动。这是两个不同层次的问题。

本例没有给出足够的抽样设计信息，因此适当的表述是：**在当前样本中，B 组的平均观测值比 A 组高 1.6；总体是否存在差异，需要进一步建立统计推断模型。**

## 单位与线性变换如何影响方差

如果原始量的单位为 U，则均值、偏差和标准差的单位为 U，SS 与方差的单位为 U²。标准差通过开平方恢复原始单位，因此更容易与测量值直接比较。[NIST 的标准差说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm)也强调了这一点。

设对每个观测实施同样的线性变换 `yᵢ = a + bxᵢ`，则：

```text
ȳ = a + bx̄
yᵢ − ȳ = b(xᵢ − x̄)

SSy = b²SSx
sy² = b²sx²
sy = |b|sx
```

所有值同时增加同一个常数不会改变方差或标准差，因为它只移动中心。所有值乘以 b，则方差乘以 b²，标准差乘以 |b|。例如重量从 g 换算为 mg 时，数值乘以 1000，因此标准差数值乘以 1000，方差数值乘以 1000000。

方差大并不自动表示质量差。评价生产质量还需要公差范围、目标值和测量误差；比较不同单位或不同测量尺度的变量，也不能直接凭方差大小得出“谁更不稳定”。

## 精确恒等式与稳定计算算法

`SS = Σxᵢ² − (Σxᵢ)²/n` 在实数代数中严格成立，但计算机使用有限精度。如果观测值都很大而彼此十分接近，这两个大数相减可能损失有效数字。例如测量值均在十亿附近，而真实波动仅为几个单位，原始平方和与校正项都很大，SS 却可能很小。

一种易懂的实现是两遍计算：第一遍求均值，第二遍求每个偏差的平方和。它通常比直接相减两个巨大平方量更稳定，但均值求和仍可能受到浮点误差影响。

流式数据可采用 Welford 更新法，只保存当前个数、均值和偏差平方和。递推平方和方法的原始文献是 [Welford（1962）](https://www.tandfonline.com/doi/abs/10.1080/00401706.1962.10490022)。令初始 `n=0`、`mean=0`、`M2=0`，每读入一个 x，按顺序更新：

```text
n = n + 1
delta = x − mean
mean = mean + delta/n
delta2 = x − mean
M2 = M2 + delta×delta2

全部数据处理完成后：
SS = M2
描述性方差 = M2/n
样本方差 = M2/(n−1)，要求 n≥2
```

这里第一次减法使用更新前的均值，第二次使用更新后的均值，不能交换顺序。其依据是加入第 n 个值后，偏差平方和增加 `((n−1)/n)×(x−旧均值)²`，恰好等于 `delta×delta2`。算法避免构造两个巨大的平方量再相减，但仍需保留足够数值精度，并在最终输出时统一舍入。

## 用 Excel 核算统计量

将 16 个零件数值放在 `A1:A16`，不要把表头包含在用于确认样本量的数值区域中。可以使用：

| 目标 | Excel 公式 | 本例结果 |
| --- | --- | ---: |
| 数值个数 | `=COUNT(A1:A16)` | 16 |
| 总和 | `=SUM(A1:A16)` | 978 |
| 原始平方和 | `=SUMSQ(A1:A16)` | 59826 |
| 均值 | `=AVERAGE(A1:A16)` | 61.125 |
| 偏差平方和 | `=DEVSQ(A1:A16)` | 45.75 |
| 样本方差 | `=VAR.S(A1:A16)` | 3.05 |
| 样本标准差 | `=STDEV.S(A1:A16)` | 约 1.7464 |
| 分母 n 的方差 | `=VAR.P(A1:A16)` | 2.859375 |
| 分母 n 的标准差 | `=STDEV.P(A1:A16)` | 约 1.6910 |

`DEVSQ` 返回偏差平方和，`SUMSQ` 返回原始数值平方和，二者不能混用。Microsoft 官方文档明确区分了[样本方差 VAR.S](https://support.microsoft.com/en-us/excel/functions/var-s-function)与[总体方差 VAR.P](https://support.microsoft.com/en-us/excel/functions/var-p-function)，并说明[STDEV.S 使用 n−1](https://support.microsoft.com/en-us/excel/functions/stdev-s-function)、[STDEV.P 使用 n](https://support.microsoft.com/en-us/excel/functions/stdev-p-function)。

将 A、B 组分别放在 `B1:B10` 和 `C1:C10`，对应使用 `=DEVSQ(B1:B10)`、`=AVERAGE(B1:B10)` 等公式，结果分别为 18.9、8.1，以及 28.1、9.7。

对于引用区域，空白、文本和逻辑值通常不会作为数值参与这些计算，而数值 0 会参与。应检查“数字是否被保存为文本”和是否漏选单元格，不能把未测量或缺失值擅自填成 0。样本方差至少需要两个有效数值；错误单元格也需要先查明原因。区域输入规则可核对 [DEVSQ 官方文档](https://support.microsoft.com/en-us/excel/functions/devsq-function)。

如果需要在 Excel 中制作严格的点图，可以将原始观测作为横坐标，将该数值在本组中第几次出现作为纵坐标，再插入散点图。两组使用相同横轴范围，纵坐标只用于防止相同数值的点重叠，并不是额外测量变量。

## 练习与解答

### 练习一：核算两种分母

数据为 `2,4,6`。求均值、SS、样本方差、样本标准差，以及分母为 n 的描述性方差。

**解答：** 均值为 4，SS 为 8。因此样本方差为 `8/(3−1)=4`，样本标准差为 2；描述性方差为 `8/3≈2.6667`。这些结果采用不同分母，含义也不同。

### 练习二：平移与缩放

某数据集的均值为 8，样本方差为 9。对每个值变换为 `y=100−2x`，求新均值、样本方差与标准差。

**解答：** 新均值为 `100−2×8=84`，样本方差为 `(-2)²×9=36`，标准差为 `|-2|×3=6`。标准差不能为负。

### 练习三：说明比较结论的范围

两个样本的均值分别为 20 和 23，但没有说明如何抽样。能否据此断言两个总体的均值具有显著差异？

**解答：** 只能断言当前两个样本的均值相差 3。总体推断还需要抽样与测量设计、独立性条件、适当概率模型以及对应的推断方法。样本均值不相等不自动构成显著性结论。

### 练习四：从流式更新核算 SS

依次读入 `2,4,6`，用 Welford 更新法求 SS。

**解答：** 读入 2 后，均值为 2、M2 为 0；读入 4 时 `delta=2`，新均值为 3、`delta2=1`，故 M2 为 2；读入 6 时 `delta=3`，新均值为 4、`delta2=2`，故 M2 增加 6，最终 SS 为 8，与定义式一致。
