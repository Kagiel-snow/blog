概率课进入连续型随机变量之后，一个很不直觉的地方是：X 明明会取到某个数，为什么 P(X = a) 却可以等于 0？要理解这一点，得把“一个点”和“一段区间”分开。

<!-- more -->

## 离散与连续的区别

骰子点数只能取 1 到 6，可以给每个点数单独分配概率。测量时间、长度这类量常用连续模型描述，概率通过密度函数在区间上的面积来计算。

对于具有概率密度 f(x) 的连续型随机变量，密度非负，整条数轴下的总面积为 1。区间概率 P(a ≤ X ≤ b) 等于 f(x) 从 a 到 b 的积分。

## 密度的高度不是概率

设 X 在 0 到 0.5 上均匀分布，那么区间内密度为 2，区间外为 0。高度虽然超过 1，但总面积是 2 × 0.5 = 1，完全符合概率要求。

例如 P(0.1 ≤ X ≤ 0.2) = 2 × (0.2 − 0.1) = 0.2。概率取决于面积，而不是直接读取曲线的高度。

## 为什么单点概率是 0

一个点没有宽度，所以在密度模型中，它对应的面积为 0。这并不表示模型里这个数被禁止取到，而是不能把连续分布理解成“给每个实数分一点正概率，再逐个相加”。

实际仪器显示 0.20 秒，通常还涉及精度和四舍五入，对应的是一个小区间。例如保留两位小数时，显示值附近的一段真实时间都可能被记录成 0.20。这个区间可以具有正概率。

对连续密度模型而言，端点的单点概率为 0，因此 P(a < X < b)、P(a ≤ X < b) 和 P(a ≤ X ≤ b) 相同。离散型变量不能直接套用这一结论。

## 分布函数是累计到哪里

分布函数 F(x) 定义为 P(X ≤ x)。它随着 x 增大而不减，从左侧的 0 累积到右侧的 1。

对于上面的均匀分布：x 小于 0 时，F(x) = 0；0 ≤ x ≤ 0.5 时，F(x) = 2x；x 大于 0.5 时，F(x) = 1。于是区间概率还可以写成 F(b) − F(a)。

做题时我先确认它是离散概率表还是连续密度，再决定用求和还是面积。特别是题目直接给出 f(x) 时，要先检查它非负、总积分为 1，而不是把 f(a) 当成 P(X = a)。
