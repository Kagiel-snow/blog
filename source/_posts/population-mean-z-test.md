假设检验（<span lang="ja" translate="no">仮説検定</span> / hypothesis testing）要回答的问题是：样本均值和某个设定值不同，这个差别能不能只用抽样的偶然波动来解释。这一篇讨论最基础的一种情况：总体服从正态分布，总体标准差 σ 已知，检验总体均值 μ 是否等于某个值。课程中称为「<span lang="ja" translate="no">母平均の検定（母分散既知）</span>」，使用的统计量是 z，所以也叫 z 检验。

方差和标准差的计算可以先看[方差与标准差笔记](/posts/statistics-variance-standard-deviation/)；概率的基本规则见[概率基本性质笔记](/posts/probability-basic-properties/)。

## 为什么样本均值服从正态分布

从正态总体 `N(μ, σ²)` 中独立抽取 n 个观测，样本均值 x̄ 的分布是：

```text
x̄ ~ N(μ, σ²/n)
```

均值仍是 μ，方差缩小为 σ²/n。样本均值的标准差 `σ/√n` 叫标准误（<span lang="ja" translate="no">標準誤差</span> / standard error）。n 越大，x̄ 越集中在 μ 附近。

把 x̄ 标准化：

```text
z = (x̄ − μ) / (σ/√n) ~ N(0, 1)
```

即使总体不是正态分布，只要 n 足够大，根据中心极限定理（<span lang="ja" translate="no">中心極限定理</span>），x̄ 也近似服从正态分布，这个方法仍可近似使用。

## 检验的五个步骤

1. **设定假设。** H₀ 是“没有差别”的说法，例如 `μ = μ₀`；H₁ 是想要证明的说法。
2. **确定显著性水平 α。** 常用 0.05 或 0.01。它是“H₀ 为真时却错误拒绝 H₀”的允许概率。
3. **计算检验统计量。** 假定 H₀ 为真，代入 `μ = μ₀`：`z = (x̄ − μ₀)/(σ/√n)`。
4. **确定拒绝域或计算 p 值。**
5. **下结论。** z 落在拒绝域内（或 p ≤ α）则拒绝 H₀，否则不拒绝 H₀。

检验的逻辑类似反证法：先假定 H₀ 成立，如果在这个假定下，观察到的结果出现的概率很小，就认为假定不太可能成立。

## 标准正态分布的临界值

| α | 双侧检验的临界值 | 单侧检验的临界值 |
| --- | --- | --- |
| 0.10 | ±1.645 | 1.282 |
| 0.05 | ±1.960 | 1.645 |
| 0.01 | ±2.576 | 2.326 |

双侧检验把 α 平分到左右两端，每端 α/2。α = 0.05 时，每端 0.025，对应 1.96。单侧检验把整个 α 放在一端，所以 α = 0.05 对应 1.645。

## 例题一：双侧检验

某工厂生产的零件长度服从标准差 σ = 0.4 mm 的正态分布，规格均值为 50.0 mm。随机抽取 25 个零件，样本均值为 50.18 mm。在 α = 0.05 下，能否认为均值偏离了 50.0 mm？

**① 假设**

```text
H₀: μ = 50.0
H₁: μ ≠ 50.0      （偏大偏小都算偏离，所以是双侧）
```

**② 显著性水平** α = 0.05，拒绝域 `|z| > 1.96`。

**③ 检验统计量**

```text
标准误 = σ/√n = 0.4/√25 = 0.4/5 = 0.08
z = (50.18 − 50.0) / 0.08 = 0.18 / 0.08 = 2.25
```

**④ 判断** `|2.25| > 1.96`，落在拒绝域内。

**⑤ 结论** 在 5% 显著性水平下拒绝 H₀，可以认为零件长度的均值偏离了 50.0 mm。

如果改用 α = 0.01，临界值是 2.576，`2.25 < 2.576`，就不能拒绝 H₀。同一份数据，结论取决于事先定下的标准。α 必须在看数据之前决定，不能看了结果再挑一个能拒绝的 α。

## 用 p 值表达同一判断

p 值（<span lang="ja" translate="no">p 値</span>）是在 H₀ 为真时，得到与观测结果同样极端或更极端结果的概率。

例题一是双侧检验：

```text
p = P(|Z| ≥ 2.25) = 2 × P(Z ≥ 2.25) = 2 × 0.0122 = 0.0244
```

`0.0244 < 0.05`，拒绝 H₀；`0.0244 > 0.01`，在 1% 水平下不拒绝。和临界值法的结论完全一致。

p 值的含义要说准确：

- p 值**不是** H₀ 为真的概率。它是在假定 H₀ 为真的前提下计算的。
- p 值小，说明数据与 H₀ 不太相容，但不说明差别在实际中有多大。
- p > α 时只能说“没有足够证据拒绝 H₀”，不能说“证明了 H₀ 为真”。

## 例题二：单侧检验

某饮料标示容量 500 mL，已知容量的标准差 σ = 6 mL。消费者团体怀疑实际容量不足，抽取 36 瓶，样本均值 497.8 mL。用 α = 0.05 检验。

```text
H₀: μ = 500
H₁: μ < 500        （只关心是否偏少，左侧检验）

标准误 = 6/√36 = 1
z = (497.8 − 500)/1 = −2.2
拒绝域：z < −1.645
```

`−2.2 < −1.645`，拒绝 H₀，可以认为平均容量少于 500 mL。p 值 = `P(Z ≤ −2.2) ≈ 0.0139`。

单侧还是双侧，要根据研究问题在收集数据之前决定。如果先看到样本均值偏小，再改成左侧检验，会让实际的错误率比名义上的 α 更高。

## 两类错误与检出力

| | H₀ 实际为真 | H₀ 实际为假 |
| --- | --- | --- |
| 拒绝 H₀ | 第一类错误（概率 α） | 正确（概率 1 − β，检出力） |
| 不拒绝 H₀ | 正确（概率 1 − α） | 第二类错误（概率 β） |

日语分别是「<span lang="ja" translate="no">第 1 種の過誤</span>」「<span lang="ja" translate="no">第 2 種の過誤</span>」「<span lang="ja" translate="no">検出力</span>」。

第一类错误是“冤枉了没有差别的情况”，第二类错误是“漏掉了真实存在的差别”。α 越小，第一类错误越少，但在样本量不变时，β 会变大。

**计算检出力**：续用例题一，若真实均值 μ = 50.2，α = 0.05 双侧检验的检出力是多少？

不拒绝域对应的样本均值范围：

```text
50.0 ± 1.96 × 0.08 = 50.0 ± 0.1568 → [49.8432, 50.1568]
```

真实 μ = 50.2 时，x̄ ~ N(50.2, 0.08²)，x̄ 落在不拒绝域内的概率：

```text
P(49.8432 ≤ x̄ ≤ 50.1568)
= P((49.8432 − 50.2)/0.08 ≤ Z ≤ (50.1568 − 50.2)/0.08)
= P(−4.46 ≤ Z ≤ −0.54)
≈ 0.2946
```

β ≈ 0.29，检出力 ≈ 0.71。也就是说，真实均值偏了 0.2 mm 时，每 100 次这样的检验约有 71 次能检出来。

提高检出力的方法：增加样本量 n（标准误变小）、真实差距更大、放宽 α。实验设计时通常先定目标检出力（如 0.8），再反推所需样本量。

## 检验与置信区间的对应

σ 已知时，μ 的 95% 置信区间（<span lang="ja" translate="no">信頼区間</span>）是：

```text
x̄ ± 1.96 × σ/√n
```

例题一：`50.18 ± 1.96 × 0.08 = 50.18 ± 0.1568 → [50.0232, 50.3368]`。

50.0 不在这个区间内，这与“α = 0.05 双侧检验拒绝 μ = 50.0”是同一件事。一般地，**α 水平的双侧检验拒绝 μ₀，当且仅当 μ₀ 不在 1 − α 置信区间内。** 置信区间还多给出了一个信息：均值大约偏离了多少（约 0.02～0.34 mm）。

## σ 未知时怎么办

实际研究中 σ 很少事先知道。用样本标准差 s 代替 σ 时，统计量

```text
t = (x̄ − μ₀) / (s/√n)
```

服从自由度 n − 1 的 t 分布，这就是 t 检验。t 分布的尾部比正态分布厚，临界值更大（如 n = 10，双侧 5% 的临界值是 2.262，而不是 1.96）。n 很大时，t 分布接近标准正态分布。

| 条件 | 统计量 | 分布 |
| --- | --- | --- |
| σ 已知（<span lang="ja" translate="no">母分散既知</span>） | z = (x̄ − μ₀)/(σ/√n) | 标准正态分布 |
| σ 未知（<span lang="ja" translate="no">母分散未知</span>） | t = (x̄ − μ₀)/(s/√n) | 自由度 n − 1 的 t 分布 |

## Excel 中的计算

| 目的 | 函数 |
| --- | --- |
| 双侧临界值 | `=NORM.S.INV(1 - 0.05/2)` → 1.96 |
| 单侧临界值 | `=NORM.S.INV(1 - 0.05)` → 1.645 |
| 右侧 p 值 | `=1 - NORM.S.DIST(z, TRUE)` |
| 双侧 p 值 | `=2 * (1 - NORM.S.DIST(ABS(z), TRUE))` |
| 单侧 p 值（右侧，直接从数据） | `=Z.TEST(数据范围, μ₀, σ)` |

`Z.TEST` 返回的是右侧的单侧 p 值，样本均值小于 μ₀ 时结果会接近 1，用于双侧检验需要自行换算：`=2 * MIN(Z.TEST(...), 1 - Z.TEST(...))`。

## 练习

1. 某考试成绩服从 σ = 15 的正态分布，往年均值 60。今年随机抽取 100 人，平均 63。用 α = 0.05 检验今年均值是否与往年不同，并求 p 值。
2. 同一题若只想检验“今年是否更高”，结论和 p 值如何变化？
3. 要使例题一的标准误降为 0.04，样本量需要多少？
4. 某人说“p = 0.03，所以 H₀ 为真的概率是 3%”。指出错误。

**解答**

1. `z = (63 − 60)/(15/10) = 2.0`，`|2.0| > 1.96`，拒绝 H₀；p = `2 × P(Z ≥ 2) ≈ 2 × 0.0228 = 0.0456`。
2. 右侧检验，临界值 1.645，`2.0 > 1.645`，仍拒绝；p ≈ 0.0228。
3. `0.4/√n = 0.04`，`√n = 10`，n = 100。标准误减半需要样本量变为 4 倍。
4. p 值是在假定 H₀ 为真的条件下，得到如此极端数据的概率，不是 H₀ 为真的概率。后者需要贝叶斯方法和先验概率才能讨论。
