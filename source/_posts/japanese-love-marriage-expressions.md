恋爱和婚姻相关的日语，在日剧、歌词和日常聊天里都很常见，但词与词之间的分寸不容易把握。「<span lang="ja" translate="no">好き</span>」和「<span lang="ja" translate="no">愛してる</span>」的重量不同，「<span lang="ja" translate="no">付き合う</span>」在不同语境里意思也不一样，「<span lang="ja" translate="no">お見合い</span>」和「<span lang="ja" translate="no">婚活</span>」也不是一回事。

这篇按照从认识到结婚的顺序整理词汇，再单独讲语法和句式。例句都是学习用的造句。

<!-- more -->

## 两条路：自由恋爱与相亲

| 日语 | 读音 | 意思 |
| --- | --- | --- |
| <span lang="ja" translate="no">恋愛結婚</span> | れんあいけっこん | 自由恋爱后结婚 |
| <span lang="ja" translate="no">お見合い</span> | おみあい | 相亲（通常经人介绍，有正式的见面程序） |
| <span lang="ja" translate="no">お見合い結婚</span> | おみあいけっこん | 相亲结婚 |
| <span lang="ja" translate="no">婚活</span> | こんかつ | 「結婚活動」的简称，为结婚主动寻找对象的活动 |
| <span lang="ja" translate="no">恋活</span> | こいかつ | 寻找恋爱对象（不一定以结婚为前提） |
| <span lang="ja" translate="no">結婚相談所</span> | けっこんそうだんじょ | 婚介所 |
| <span lang="ja" translate="no">マッチングアプリ</span> | | 交友/配对应用 |
| <span lang="ja" translate="no">合コン</span> | ごうコン | 联谊（「合同コンパ」），男女双方各几人一起吃饭 |
| <span lang="ja" translate="no">街コン</span> | まちコン | 在一个街区举办的大型联谊活动 |
| <span lang="ja" translate="no">紹介</span> | しょうかい | 朋友介绍 |
| <span lang="ja" translate="no">一目惚れ</span> | ひとめぼれ | 一见钟情 |
| <span lang="ja" translate="no">職場恋愛</span> | しょくばれんあい | 办公室恋情 |

「<span lang="ja" translate="no">お見合い</span>」传统上由长辈或媒人（<span lang="ja" translate="no">仲人・なこうど</span>）安排，双方先交换「<span lang="ja" translate="no">釣書（つりしょ）</span>」（写有个人经历和家庭情况的资料）和照片，再正式见面。现在结婚相谈所里的见面也常叫「<span lang="ja" translate="no">お見合い</span>」。「<span lang="ja" translate="no">婚活</span>」范围更广，参加相谈所、用配对应用、去联谊，只要目的是结婚，都可以叫婚活。

相亲相关的固定说法：

- <span lang="ja" translate="no">お見合いをする</span>：相亲
- <span lang="ja" translate="no">お見合い写真</span>：相亲照片
- <span lang="ja" translate="no">仮交際（かりこうさい）</span>：相谈所里，见面后双方同意继续接触的阶段，可以同时和几个人进行
- <span lang="ja" translate="no">真剣交際（しんけんこうさい）</span>：确定只和一个人以结婚为前提交往
- <span lang="ja" translate="no">成婚（せいこん）</span>：在相谈所的语境中，指确定结婚、退会
- <span lang="ja" translate="no">条件が合う</span>：条件相符

## 从认识到交往

| 阶段 | 日语 | 意思 |
| --- | --- | --- |
| 认识 | <span lang="ja" translate="no">出会う（であう）</span> | 相遇、认识 |
| 在意 | <span lang="ja" translate="no">気になる</span> | 有点在意、开始注意某人 |
| 喜欢 | <span lang="ja" translate="no">好きになる</span> | 喜欢上 |
| 暗恋 | <span lang="ja" translate="no">片思い（かたおもい）</span> | 单恋 |
| 两情相悦 | <span lang="ja" translate="no">両思い（りょうおもい）</span> | 互相喜欢 |
| 约会 | <span lang="ja" translate="no">デート（する）</span> | 约会 |
| 暧昧 | <span lang="ja" translate="no">友達以上恋人未満</span> | 友达以上、恋人未满 |
| 告白 | <span lang="ja" translate="no">告白（こくはく）する・告る（こくる）</span> | 表白（后者是口语） |
| 交往 | <span lang="ja" translate="no">付き合う（つきあう）</span> | 交往、谈恋爱 |
| 恋人 | <span lang="ja" translate="no">彼氏・彼女・恋人・パートナー</span> | 男朋友、女朋友、恋人、伴侣 |
| 热恋 | <span lang="ja" translate="no">ラブラブ</span> | 恩爱、甜蜜（口语） |

「<span lang="ja" translate="no">彼女</span>」既是第三人称代词“她”，也是“女朋友”。「<span lang="ja" translate="no">彼女がいる</span>」是“有女朋友”，不能理解成“她在”。

「<span lang="ja" translate="no">付き合う</span>」有两个意思：

- <span lang="ja" translate="no">彼と付き合っています。</span>（在和他交往。）
- <span lang="ja" translate="no">買い物に付き合ってくれない？</span>（能陪我去买东西吗？）

区别在于有没有「<span lang="ja" translate="no">に</span>」后接一个事情。「<span lang="ja" translate="no">人と付き合う</span>」是交往，「<span lang="ja" translate="no">事に付き合う</span>」是陪同。

## 喜欢的几种程度

| 说法 | 程度与语感 |
| --- | --- |
| <span lang="ja" translate="no">気になる</span> | 有好感，还没确定 |
| <span lang="ja" translate="no">好き</span> | 喜欢。告白时最常用 |
| <span lang="ja" translate="no">大好き</span> | 很喜欢，语气更直接、更热情 |
| <span lang="ja" translate="no">恋してる</span> | 正在恋爱中，强调心动的状态 |
| <span lang="ja" translate="no">愛してる</span> | 爱。很重，日常生活中很少当面说 |
| <span lang="ja" translate="no">惚れる（ほれる）</span> | 迷上、倾心，常用「<span lang="ja" translate="no">惚れた</span>」 |

日语里表达心意往往比较含蓄。夏目漱石把“I love you”译作「<span lang="ja" translate="no">月が綺麗ですね</span>」的说法流传很广，但没有可靠的文献证据，可以当作有名的传说了解。

## 告白时的句式

**1. 「〜が好きです」**

<div lang="ja" translate="no">

- 前から〇〇さんのことが好きでした。
- ずっと好きでした。

</div>

“喜欢的对象”用「<span lang="ja" translate="no">が</span>」标记，而不是「<span lang="ja" translate="no">を</span>」。「<span lang="ja" translate="no">好き</span>」是形容动词，「<span lang="ja" translate="no">〜が好きだ</span>」中的「<span lang="ja" translate="no">が</span>」表示对象。加上「<span lang="ja" translate="no">のこと</span>」（〇〇さんのこと）语气更柔和，指“关于这个人的一切”。

用过去式「<span lang="ja" translate="no">好きでした</span>」不代表现在不喜欢了，而是“一直以来都喜欢（到现在才说出口）”的意思。

**2. 「〜てください」「〜てくれませんか」**

<div lang="ja" translate="no">

- 付き合ってください。
- 僕と付き合ってくれませんか。
- 結婚を前提に付き合ってください。

</div>

「<span lang="ja" translate="no">〜を前提に</span>」是“以……为前提”，在婚活场合很常用。

**3. 「〜てもいいですか」**（请求许可）

<div lang="ja" translate="no">

- 連絡先を聞いてもいいですか。
- また会ってもいいですか。

</div>

**4. 回应**

| 场合 | 日语 |
| --- | --- |
| 接受 | <span lang="ja" translate="no">はい、よろしくお願いします。／私も好きでした。</span> |
| 委婉拒绝 | <span lang="ja" translate="no">気持ちは嬉しいけど、ごめんなさい。</span> |
| 要时间 | <span lang="ja" translate="no">少し考えさせてください。</span> |

「<span lang="ja" translate="no">考えさせてください</span>」是使役形「<span lang="ja" translate="no">考えさせる</span>」+「<span lang="ja" translate="no">てください</span>」，字面是“请让我考虑一下”。

| <span lang="ja" translate="no">手をつなぐ</span> | 牵手 |

| <span lang="ja" translate="no">喧嘩（けんか）する</span> | 吵架 |

「<span lang="ja" translate="no">振る</span>」的被动形「<span lang="ja" translate="no">振られる</span>」用得更多：<span lang="ja" translate="no">彼女に振られた。</span>（被女朋友甩了。）这是日语的“受害被动”，主语是受到影响的人。

## 求婚与结婚

| 日语 | 意思 |
| --- | --- |
| <span lang="ja" translate="no">プロポーズする</span> | 求婚 |
| <span lang="ja" translate="no">婚約（こんやく）する</span> | 订婚 |
| <span lang="ja" translate="no">婚約指輪・結婚指輪</span> | 订婚戒指、结婚戒指 |
| <span lang="ja" translate="no">結納（ゆいのう）</span> | 订婚时两家交换聘礼的传统仪式 |
| <span lang="ja" translate="no">両親に挨拶する</span> | 去拜见对方父母 |
| <span lang="ja" translate="no">入籍（にゅうせき）する</span> | 登记结婚（口语中常用） |
| <span lang="ja" translate="no">婚姻届（こんいんとどけ）を出す</span> | 提交结婚申请书 |
| <span lang="ja" translate="no">結婚式・披露宴（ひろうえん）</span> | 婚礼、婚宴 |
| <span lang="ja" translate="no">新婚旅行・ハネムーン</span> | 蜜月旅行 |
| <span lang="ja" translate="no">夫婦（ふうふ）</span> | 夫妻 |
| <span lang="ja" translate="no">夫・妻／主人・家内</span> | 丈夫、妻子（后两个较传统） |
| <span lang="ja" translate="no">旦那さん・奥さん</span> | 称呼别人的丈夫、妻子 |
| <span lang="ja" translate="no">共働き（ともばたらき）</span> | 双职工 |
| <span lang="ja" translate="no">離婚（りこん）</span> | 离婚 |

日本结婚在法律上以提交「<span lang="ja" translate="no">婚姻届</span>」为准，举不举办婚礼不影响法律效力。「<span lang="ja" translate="no">入籍</span>」严格说是“进入户籍”，但日常基本当作“登记结婚”用。

称呼配偶：说自己的配偶，用「<span lang="ja" translate="no">夫・妻</span>」最中性；说别人的配偶，用「<span lang="ja" translate="no">ご主人・奥さん・旦那さん</span>」。「<span lang="ja" translate="no">主人</span>」「<span lang="ja" translate="no">家内</span>」字面带有“一家之主”“家里的人”的意思，现在有人刻意避开，改用「<span lang="ja" translate="no">夫・妻・パートナー</span>」。

求婚的经典句式：

<div lang="ja" translate="no">

- 結婚してください。
- 僕と結婚してくれませんか。
- これからもずっと一緒にいてください。

</div>

## 婚活与相亲中的会话

结婚相谈所或相亲场合，说话要比普通约会更礼貌，通常使用です・ます体。

<div lang="ja" translate="no">

- はじめまして。本日はよろしくお願いいたします。
- お休みの日は何をされていますか。
- 結婚後もお仕事は続けたいとお考えですか。
- 将来はどちらに住みたいですか。
- 本日はありがとうございました。またお会いできたら嬉しいです。

</div>

「<span lang="ja" translate="no">されています</span>」是「<span lang="ja" translate="no">する</span>」的尊敬语形式（被动形兼作尊敬），「<span lang="ja" translate="no">お考えですか</span>」是「<span lang="ja" translate="no">お〜です</span>」的尊敬语。问对方的事情用尊敬语，说自己的事用谦让语（「<span lang="ja" translate="no">いたします</span>」）。

婚活中常听到的说法：

| 日语 | 意思 |
| --- | --- |
| <span lang="ja" translate="no">価値観が合う</span> | 价值观相合 |
| <span lang="ja" translate="no">結婚観</span> | 婚姻观 |
| <span lang="ja" translate="no">年収（ねんしゅう）</span> | 年收入 |
| <span lang="ja" translate="no">お断り（おことわり）</span> | 拒绝（相谈所里表示不再继续） |
| <span lang="ja" translate="no">ご縁（ごえん）がある・ない</span> | 有缘、无缘 |
| <span lang="ja" translate="no">理想が高い</span> | 要求高 |
| <span lang="ja" translate="no">妥協（だきょう）する</span> | 妥协、降低要求 |

「<span lang="ja" translate="no">今回はご縁がなかったということで…</span>」是婚活中委婉拒绝的典型说法，字面是“这次就当作没有缘分吧”，把原因归给“缘分”而不是对方。

## 语法要点归纳

**授受动词表达恋爱中的给予**

| 句型 | 视角 | 例句 |
| --- | --- | --- |
| 〜てあげる | 我为别人做 | <span lang="ja" translate="no">彼女に料理を作ってあげた。</span> |
| 〜てくれる | 别人为我做 | <span lang="ja" translate="no">彼が駅まで送ってくれた。</span> |
| 〜てもらう | 我请别人做 / 从别人那里得到 | <span lang="ja" translate="no">誕生日に花を買ってもらった。</span> |

「<span lang="ja" translate="no">〜てくれる</span>」带有感谢的语气，说对方为自己做的事时几乎总用它。如果说「<span lang="ja" translate="no">彼が駅まで送った</span>」，只是陈述事实，听起来像旁观者。

**「〜たい」和「〜てほしい」**

- <span lang="ja" translate="no">一緒にいたい。</span>（我想和你在一起。自己的愿望）
- <span lang="ja" translate="no">そばにいてほしい。</span>（希望你在我身边。对别人的愿望）

**「〜ようになる」表示变化**

- <span lang="ja" translate="no">一緒に過ごすうちに、彼のことを好きになっていった。</span>（在一起相处的过程中，渐渐喜欢上了他。）
- <span lang="ja" translate="no">付き合ってから、料理をするようになった。</span>（交往之后开始做饭了。）

「<span lang="ja" translate="no">〜うちに</span>」表示“在……的过程中（不知不觉地）”。

**「〜わけではない」委婉否定**

- <span lang="ja" translate="no">嫌いなわけじゃないけど、今は恋愛する気になれない。</span>（并不是讨厌你，只是现在没心思谈恋爱。）

## 易混词辨析

| 词 | 区别 |
| --- | --- |
| <span lang="ja" translate="no">恋（こい）</span>／<span lang="ja" translate="no">愛（あい）</span> | 恋偏向心动、渴望；愛偏向长久的关怀，也可用于家人 |
| <span lang="ja" translate="no">恋人</span>／<span lang="ja" translate="no">愛人</span> | 恋人是男女朋友；愛人在日语里通常指婚外情对象，与中文的“爱人”完全不同 |
| <span lang="ja" translate="no">浮気</span>／<span lang="ja" translate="no">不倫</span> | 不倫特指涉及已婚者的关系 |
| <span lang="ja" translate="no">結婚</span>／<span lang="ja" translate="no">入籍</span> | 結婚是总的概念；入籍偏向法律手续 |
| <span lang="ja" translate="no">お見合い</span>／<span lang="ja" translate="no">婚活</span> | お見合い是一种见面方式；婚活是所有找结婚对象的活动的总称 |

最需要注意的是「<span lang="ja" translate="no">愛人</span>」。中文说“这是我爱人”指配偶，日语说「<span lang="ja" translate="no">私の愛人です</span>」会被理解为婚外情对象。

## 练习

把下列句子译成日语：

1. 我们是通过朋友介绍认识的。
2. 交往三年后，他向我求婚了。
3. 并不是不想结婚，只是还没遇到合适的人。
4. 被他甩了以后，我难过了很久。

**参考译文**

<div lang="ja" translate="no">

1. 私たちは友達の紹介で知り合いました。
2. 付き合って三年目に、彼がプロポーズしてくれました。
3. 結婚したくないわけではなくて、まだいい人に出会えていないだけです。
4. 彼に振られてから、しばらく落ち込んでいました。

</div>

第 2 句用「<span lang="ja" translate="no">してくれました</span>」表示受益；第 4 句用被动「<span lang="ja" translate="no">振られて</span>」，主语是“我”。
