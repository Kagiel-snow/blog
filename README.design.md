## 修改入口

- `_config.butterfly.yml`：导航分组、固定头图、主题主色、字体大小、摘要长度、简洁目录，以及装饰动画开关。

- `tools/i18n/appearance.cjs`：构建时给 Butterfly 输出添加原生 `details` 折叠面板；由 `html.cjs` 调用。没有修改第三方主题源码。

- `source/css/sections.css` 与 `tools/i18n/sections.cjs`：音乐、图片、动画、友链、关于、标签和分类的独立栏目布局；它们共享蓝白灰变量，正文文章继续使用原阅读布局。

## 音乐稳定性（2026-10-15）

经常出错的主要原因：网易云热歌榜里大约七成歌曲是会员或版权受限，Meting 对这些歌返回 404，原来的播放器遇到一首就停下。现在：

- 播放前先请求一次 Meting 的音源跳转（不跟随跳转，不下载音频）。404 等 4xx 视为暂无音源，卡片显示灰色的「暂无音源」；音乐页会两首一批地预先标出当前显示的歌曲。
- 自动下一首或出错时跳过受限歌曲，并提示「《A》暂无音源，已跳到《B》」。连续跳过 8 首（`maxSkips`）后停下并显示「重试播放」，重试会清空标记。
- 已经在播放的歌，因为暂停太久导致签名链接过期时，会从原位置重新连接一次，而不是直接跳过。
- `music.json` 的 `endpoints` 依次尝试 `api.i-meto.com` 和 `api.injahow.cn`，主接口不可用时自动换用备用接口，并在之后优先使用能用的接口。
- 如果想更少看到「暂无音源」，可以在音乐页换一个会员歌曲较少的歌单。
