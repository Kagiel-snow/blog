# 灰白蓝视觉方案

保留 Hexo 8 / Butterfly 5.6、多语言构建和原有内容，只维护主题配置与独立覆盖层。

## 修改入口

- `_config.butterfly.yml`：导航分组、固定头图、主题主色、字体大小、摘要长度、简洁目录，以及装饰动画开关。
- `source/css/custom.css`：颜色变量、卡片、正文排版、响应式布局、夜间模式、音乐浮层和看板娘位置。浅色/深色方案集中在文件开头。
- `source/js/appearance.js`：播放器关闭交互和看板娘的本机显示偏好，不改动文章内容或播放列表。
- `tools/i18n/appearance.cjs`：构建时给 Butterfly 输出添加原生 `details` 折叠面板；由 `html.cjs` 调用。没有修改第三方主题源码。
- `i18n/locales.json`：新导航分组与新增控件的四语言文案。
- `source/css/sections.css` 与 `tools/i18n/sections.cjs`：音乐、图片、动画、友链、关于、标签和分类的独立栏目布局；它们共享蓝白灰变量，正文文章继续使用原阅读布局。
- `source/data/collections.json`、`i18n/sections.json`：媒体清单和栏目四语言文案。具体维护见 `README.collections.md`。

## 交互

- 导航入口收纳到「文章」「收藏」；移动端默认收起这两个分组，语言列表继续直接显示。
- 首页最新文章、归档和网站信息可以点击展开，内容仍保留在 HTML 中。
- 左下角「音乐」打开原播放器；收起面板不会停止当前音乐。支持关闭按钮、点击外部和 Escape。
- 看板娘在宽度至少 1440px 的窗口显示，放在内容区外侧。其显示开关会记住本机选择；音乐面板打开时临时隐藏。窄屏不显示，避免挡住内容。
- 文章页使用 Butterfly 的简洁目录模式，继续保留目录、评论、分享和打赏。
- 保留日夜切换，并响应系统的减少动画偏好。

## 构建与检查

```sh
npm run build
npm run check
npm test
npm run preview
```

预览 `http://127.0.0.1:4000/`，以及 `/zh-tw/`、`/ja/`、`/en/`。修改源码后需要重新构建并刷新页面。部署继续沿用现有 GitHub Pages 工作流（见 `README.i18n.md`）。不要仅执行原生 `hexo generate` 来替代本站构建。

Windows 下若构建最后一步提示 `EPERM` 无法替换 `public`，先停止预览服务，再运行构建并重新启动预览；正在读取媒体的连接可能占用输出目录。
