# 灰白蓝视觉方案

保留 Hexo 8 / Butterfly 5.6、多语言构建和原有内容，只维护主题配置与独立覆盖层。

## 修改入口

- `_config.butterfly.yml`：导航分组、固定头图、主题主色、字体大小、摘要长度、简洁目录，以及装饰动画开关。
- `source/css/custom.css`：颜色变量、卡片、正文排版、响应式布局、夜间模式、音乐浮层和看板娘位置。浅色/深色方案集中在文件开头。
- `source/js/appearance.js`：播放器关闭交互，不改动文章内容或播放列表；看板娘交互独立在 `source/js/mascot.js`。
- `tools/i18n/appearance.cjs`：构建时给 Butterfly 输出添加原生 `details` 折叠面板；由 `html.cjs` 调用。没有修改第三方主题源码。
- `i18n/locales.json`：新导航分组与新增控件的四语言文案。
- `source/css/sections.css` 与 `tools/i18n/sections.cjs`：音乐、图片、动画、友链、关于、标签和分类的独立栏目布局；它们共享蓝白灰变量，正文文章继续使用原阅读布局。
- `source/data/collections.json`、`i18n/sections.json`：媒体清单和栏目四语言文案。具体维护见 `README.collections.md`。

## 交互

- 文章列表每页 5 篇：`_config.yml` 的 `index_generator.per_page` 控制首页，`per_page` 控制归档、分类和标签列表。超过一页时显示页码、上一页／下一页和当前页提示；沿用 Hexo 静态路由与 PJAX。样式在 `source/css/custom.css`，可访问性和文字增强在 `tools/i18n/appearance.cjs`；不改变文章内的上一篇／下一篇。
- 2026-10-06 新增软件工程笔记封面 `software-snow-evening.jpg`，来自用户图库的「【哲风壁纸】下雪-二次元-冬季.jpg」（3840 × 2160），保留原图与原分辨率。

- 导航入口收纳到「文章」「收藏」；移动端默认收起这两个分组，语言列表继续直接显示。
- 首页最新文章、归档和网站信息可以点击展开，内容仍保留在 HTML 中。
- 左下角「音乐」打开原播放器；收起面板不会停止当前音乐。支持关闭按钮、点击外部和 Escape。
- 看板娘改为头像定制的「KGY」，简介「ONLY KGY」：本地透明少女素材、眼睛跟随鼠标、轻微姿态变化、点击互动和连续简短对话。聊天面板可手动开启免费 WebLLM 本地 AI（首次约 300 MB），无付费密钥和聊天上传；加载失败保留简短对话。`source/js/mascot*`、`source/css/mascot.css` 与 `source/img/mascot/` 独立维护，不依赖旧远程 Live2D 模型。详见 `README.mascot.md`。
- 宽屏且内容左侧至少有 185px 空白时显示全身，按空白宽度缩放；1200px 以上且侧边至少有 90px 空白时收成圆形头像。其余窗口默认只显示左下角看板娘开关，点击打开对话。音乐面板打开时临时隐藏，站内 PJAX 导航保留同一角色和对话。
- 新看板娘使用独立的显示偏好键，首次默认显示，不继承旧模型的隐藏状态。支持键盘、Escape 收起、减少动态效果，以及图形加速不可用时的静态图片回退；角色对话为本地规则，不是联网 AI 服务。
- 文章页使用 Butterfly 的简洁目录模式，继续保留目录、评论、分享和打赏。
- 保留日夜切换，并响应系统的减少动画偏好。
